### THE PROBLEM

Right now, if we load everything into one LLM's context, the narrator knows EVERYTHING. It knows Miranda might recognize the soldier. It knows Vasile's fate before the player discovers it. It knows Heisenberg's betrayal conditions. It knows which fragments lead somewhere and which dead-end. It knows the player's own backstory before the player does.

That's not a game. That's a narrator trying really hard to pretend it doesn't know things. And LLMs are TERRIBLE at pretending they don't know things — the knowledge bleeds through in word choice, emphasis, narrative framing, NPC reactions. The main LLM will unconsciously foreshadow, unconsciously steer, unconsciously treat the soldier like someone with a past even when it's supposed to be treating him like a blank.

### THE SOLUTION

Two brains. Split responsibility.

```
CRITICAL RULES FOR THE BRIEFING:

  1. "narration_guidance" tells the narrator HOW to
     describe something without revealing WHY. "Describe
     the tripwire through environmental detail" not
     "Moreau set a tripwire because he's scared."

  2. "withhold" is explicit. Haiku LISTS what the narrator
     must NOT include. This prevents bleed. The narrator
     doesn't know the cave church is nearby so it
     CAN'T accidentally describe a draft from below or
     a faint carved symbol on the floor.

  3. "DO_NOT_REVEAL" in npc_direction is per-character
     information gating. Moreau's card might be loaded
     in the narrator's lorebook (triggered by location),
     but Haiku tells it which PARTS of the card to
     suppress this turn. The narrator plays Moreau's
     Cowering state but doesn't reference his aquatic
     form because Haiku said don't.

  4. "offscreen_events" can be marked narrator-visible
     or narrator-hidden. Hidden events are resolved by
     Haiku and stored — they surface only when the
     player takes an action that would reveal them
     (asking Elena about her father, visiting the east
     fence, etc). The narrator literally cannot
     foreshadow Leonardo's safe return because it
     doesn't know Leonardo went out.

  5. Fragment triggers are Haiku's sole domain. The
     narrator NEVER decides "this should trigger a
     memory." Haiku evaluates the stimulus against the
     fragment map and either includes a fragment in the
     briefing or doesn't. The narrator receives "the PC
     experiences a brief flash: [content]" and writes
     it into the scene. It doesn't know what the fragment
     MEANS or where it LEADS.
```

### THE WALL — In Code

This is the heart. Here's how it actually works:

```python
# engine/wall.py — The Wall

import json
from engine.gm import GameMaster
from engine.narrator import Narrator
from engine.state import StateManager

class Wall:
    """
    The information barrier between the GM (Haiku)
    and the Narrator (Sonnet/Opus).

    The GM sees everything.
    The Narrator sees only what the GM authorizes.
    The Wall enforces the boundary.
    """

    def __init__(self, config):
        self.gm = GameMaster(config)
        self.narrator = Narrator(config)
        self.state = StateManager()
        self.revelation_log = []  # tracks what narrator knows

    async def process_turn(self, player_input: str) -> dict:
        """
        The core loop. Every player action flows through here.

        1. Player input → GM
        2. GM → briefing packet
        3. Briefing → filtered context for narrator
        4. Narrator → prose response
        5. State updates saved
        6. Return display package to UI
        """

        # ── STEP 1: GM evaluates ──
        briefing = await self.gm.evaluate(
            player_input=player_input,
            pc_state=self.state.pc,
            world_state=self.state.world,
            vault=self.state.vault,
            fragment_map=self.state.fragments,
            revelation_log=self.revelation_log
        )

        # ── STEP 2: Apply state updates from GM ──
        self.state.apply_updates(briefing["state_updates"])

        # ── STEP 3: Track what's been revealed ──
        newly_revealed = briefing["information_release"].get(
            "reveal_this_turn", []
        )
        self.revelation_log.extend(newly_revealed)

        # ── STEP 4: Build narrator context ──
        # THIS is where the wall enforces the barrier.
        # The narrator gets ONLY:
        #   - its system prompt (narrator voice, rules)
        #   - the world card (public, no secrets)
        #   - PUBLIC character cards for present NPCs
        #   - any PREVIOUSLY revealed private info
        #   - this turn's briefing (scene, resolution,
        #     guidance, released info)
        #   - chat history
        #   - author's note
        #
        # It does NOT get:
        #   - the vault
        #   - the fragment map
        #   - private card sections not yet released
        #   - the GM's reasoning
        #   - the withhold list (it can't withhold what
        #     it doesn't know to withhold — it simply
        #     never receives it)

        narrator_context = self.build_narrator_context(
            briefing=briefing,
            npcs_present=briefing["scene_context"]["npcs_present"]
        )

        # ── STEP 5: Narrator generates ──
        prose = await self.narrator.generate(
            context=narrator_context,
            player_input=player_input
        )

        # ── STEP 6: Assemble display package ──
        return {
            "prose": prose,
            "hud": briefing["hud_data"],
            "portraits": self.get_portraits(
                npcs=briefing["scene_context"]["npcs_present"],
                states=briefing.get("npc_states", {})
            ),
            "fragments": briefing["information_release"].get(
                "fragment_trigger", None
            )
        }

    def build_narrator_context(self, briefing, npcs_present):
        """
        Assembles ONLY what the narrator is allowed to see.
        """
        context = {
            "system": self.narrator.system_prompt,
            "world": self.state.world_public,
            "characters": {},
            "briefing": {
                # scene and resolution — yes
                "scene_context": briefing["scene_context"],
                "action_resolution": briefing["action_resolution"],
                # npc direction — yes (behavior, not secrets)
                "npc_direction": briefing["npc_direction"],
                # revealed info — yes (cumulative)
                "revealed_info": self.revelation_log,
                # withhold list — NO (the narrator never sees
                # what it's not supposed to know, so it can't
                # accidentally reference it)
            },
            "chat_history": self.state.chat_history[-20:],
            "authors_note": self.state.authors_note
        }

        # load PUBLIC cards + any released private sections
        for npc in npcs_present:
            context["characters"][npc] = (
                self.state.get_narrator_card(
                    npc, self.revelation_log
                )
            )

        return context

    def get_portraits(self, npcs, states):
        """
        Returns portrait file paths based on NPC states.
        """
        portraits = {}
        for npc in npcs:
            state = states.get(npc, "default")
            portraits[npc] = f"data/characters/{npc}/portraits/{state}.webp"
        portraits["pc"] = self.get_pc_portrait()
        return portraits
```

```python
import json
import httpx

class GameMaster:
    """
    Haiku. Knows everything. Tells the narrator only
    what it's allowed to.
    """

    def __init__(self, config):
        self.api_key = config["haiku_api_key"]
        self.model = config.get("gm_model", "claude-3-haiku-20240307")
        self.endpoint = config["api_endpoint"]
        self.system_prompt = self._load_gm_prompt()

    def _load_gm_prompt(self):
        return """You are the Game Master for 'The Valley,' a gothic
horror-romance survival sandbox. You manage ALL hidden state,
mechanical resolution, and information gating.

You output ONLY structured JSON briefing packets. No prose.
No commentary. No markdown. Just the packet.

BRIEFING FORMAT:
{
  "scene_context": {
    "location": "",
    "time": "",
    "weather": "",
    "npcs_present": [],
    "npcs_nearby": [],
    "ambient": ""
  },
  "action_resolution": {
    "player_action": "",
    "mechanical_result": "",
    "narration_guidance": ""
  },
  "information_release": {
    "reveal_this_turn": [],
    "withhold": [],
    "fragment_trigger": null,
    "discovery_unlock": null
  },
  "npc_direction": {},
  "npc_states": {},
  "state_updates": {
    "pc": {},
    "world": {},
    "updated_json": {}
  },
  "hud_data": {}
}

RULES:
- NEVER release information before its gate conditions are met
- ALWAYS include withhold list
- Resolve ALL mechanical checks (stat vs difficulty)
- Track fragment triggers against stimulus context
- Offscreen events resolve silently — mark narrator-visible
  or narrator-hidden
- Guard the vault."""

    async def evaluate(self, player_input, pc_state,
                       world_state, vault, fragment_map,
                       revelation_log):
        """
        Send full state to Haiku, receive briefing packet.
        """
        message = {
            "player_input": player_input,
            "pc_state": pc_state,
            "world_state": world_state,
            "vault": vault,
            "fragment_map": fragment_map,
            "already_revealed": revelation_log
        }

        async with httpx.AsyncClient() as client:
            response = await client.post(
                self.endpoint,
                headers={
                    "x-api-key": self.api_key,
                    "content-type": "application/json",
                    "anthropic-version": "2023-06-01"
                },
                json={
                    "model": self.model,
                    "max_tokens": 2000,
                    "system": self.system_prompt,
                    "messages": [{
                        "role": "user",
                        "content": json.dumps(message)
                    }]
                },
                timeout=30.0
            )

        result = response.json()
        content = result["content"][0]["text"]

        # parse the briefing packet
        return json.loads(content)
```

```python
# engine/state.py — State Manager

import json
from pathlib import Path

class StateManager:
    """
    Manages all state and enforces the public/private
    card split.
    """

    def __init__(self, save_path=None):
        self.data_dir = Path("data")
        self.pc = self._load("pc.json")
        self.world = self._load("world_state.json")
        self.world_public = self._load("world.json")
        self.vault = self._load("vault.json")
        self.fragments = self._load("fragment_map.json")
        self.chat_history = []
        self.authors_note = ""

        if save_path:
            self.load_save(save_path)

    def _load(self, filename):
        path = self.data_dir / filename
        if path.exists():
            return json.loads(path.read_text())
        return {}

    def get_narrator_card(self, npc_id: str,
                          revelation_log: list) -> dict:
        """
        Returns the narrator's version of an NPC card:
        public data + any private sections that have been
        released via the revelation log.

        THE WALL IS HERE. This function is the boundary.
        """
        char_dir = self.data_dir / "characters" / npc_id
        public = json.loads(
            (char_dir / "public.json").read_text()
        )
        private = json.loads(
            (char_dir / "private.json").read_text()
        )

        # check what private sections have been unlocked
        narrator_card = dict(public)

        for entry in revelation_log:
            if entry.get("npc") == npc_id:
                section = entry.get("section")
                if section and section in private:
                    narrator_card[section] = private[section]

        return narrator_card

    def apply_updates(self, updates: dict):
        """Apply GM's state updates."""
        if "pc" in updates:
            self._deep_merge(self.pc, updates["pc"])
        if "world" in updates:
            self._deep_merge(self.world, updates["world"])
        if "updated_json" in updates:
            full = updates["updated_json"]
            if "pc" in full:
                self.pc = full["pc"]
            if "world" in full:
                self.world = full["world"]

    def save_game(self, slot_name: str):
        """Snapshot everything."""
        save = {
            "pc": self.pc,
            "world": self.world,
            "vault": self.vault,
            "fragments": self.fragments,
            "chat_history": self.chat_history,
            "authors_note": self.authors_note
        }
        save_path = self.data_dir / "saves" / f"{slot_name}.json"
        save_path.parent.mkdir(parents=True, exist_ok=True)
        save_path.write_text(json.dumps(save, indent=2))

    def load_save(self, slot_name: str):
        """Restore from snapshot."""
        save_path = self.data_dir / "saves" / f"{slot_name}.json"
        save = json.loads(save_path.read_text())
        self.pc = save["pc"]
        self.world = save["world"]
        self.vault = save["vault"]
        self.fragments = save["fragments"]
        self.chat_history = save.get("chat_history", [])
        self.authors_note = save.get("authors_note", "")

    @staticmethod
    def _deep_merge(base: dict, updates: dict):
        for key, value in updates.items():
            if (key in base and isinstance(base[key], dict)
                    and isinstance(value, dict)):
                StateManager._deep_merge(base[key], value)
            else:
                base[key] = value
```

```python
# main.py — Launches the app

import webview
import asyncio
import json
from pathlib import Path
from engine.wall import Wall

class GameAPI:
    """
    Bridge between the pywebview UI and the game engine.
    The UI calls these methods via pywebview's JS-Python bridge.
    """

    def __init__(self):
        config = self._load_config()
        self.wall = Wall(config)
        self.ready = False

    def _load_config(self):
        config_path = Path("config.yaml")
        if config_path.exists():
            import yaml
            return yaml.safe_load(config_path.read_text())
        # fallback defaults
        return {
            "haiku_api_key": "",
            "narrator_api_key": "",
            "api_endpoint": "https://api.anthropic.com/v1/messages",
            "gm_model": "claude-3-5-haiku-20241022",
            "narrator_model": "claude-sonnet-4-20250514",
            "narrator_context_window": 32000
        }

    def submit_action(self, player_input: str) -> str:
        """
        Called from JS when the player hits enter.
        Returns JSON display package.
        """
        loop = asyncio.new_event_loop()
        result = loop.run_until_complete(
            self.wall.process_turn(player_input)
        )
        loop.close()

        # also track in chat history
        self.wall.state.chat_history.append({
            "role": "user",
            "content": player_input
        })
        self.wall.state.chat_history.append({
            "role": "assistant",
            "content": result["prose"]
        })

        return json.dumps(result)

    def save_game(self, slot_name: str) -> str:
        self.wall.state.save_game(slot_name)
        return json.dumps({"status": "saved", "slot": slot_name})

    def load_game(self, slot_name: str) -> str:
        self.wall.state.load_save(slot_name)
        return json.dumps({"status": "loaded", "slot": slot_name})

    def get_initial_state(self) -> str:
        """Returns starting HUD data and opening scene trigger."""
        return json.dumps({
            "hud": {
                "hp": self.wall.state.pc.get("vitals", {})
                    .get("health", {}).get("current", 1.0),
                "stamina": self.wall.state.pc.get("vitals", {})
                    .get("stamina", {}).get("current", 1.0),
                "mold": self.wall.state.pc.get("vitals", {})
                    .get("mold_exposure", {}).get("level", 0.0),
                "location": "Village Outskirts",
                "time": "Late Morning",
                "days": 18,
                "weather": "Heavy Snow"
            }
        })

    def update_authors_note(self, note: str) -> str:
        self.wall.state.authors_note = note
        return json.dumps({"status": "updated"})

    def send_feedback(self, fb_type: str, detail: str) -> str:
        """Injects feedback anchor for next narrator generation."""
        tag = f"[FEEDBACK: {fb_type} — {detail}]"
        if not hasattr(self.wall, '_feedback_queue'):
            self.wall._feedback_queue = []
        self.wall._feedback_queue.append(tag)
        return json.dumps({"status": "feedback_queued", "tag": tag})


def main():
    api = GameAPI()
    window = webview.create_window(
        title="The Valley",
        url="ui/index.html",
        js_api=api,
        width=1100,
        height=750,
        min_size=(800, 500),
        resizable=True,
        background_color="#0a0a0f"
    )
    webview.start(debug=False)


if __name__ == "__main__":
    main()
```

```javascript
// ui/app.js — Front-end logic

// ── INPUT HANDLING ──

const input = document.getElementById('player-input');
const narrative = document.getElementById('narrative-scroll');

input.addEventListener('keydown', async (e) => {
  if (e.key === 'Enter' && input.value.trim()) {
    const action = input.value.trim();
    input.value = '';
    input.disabled = true;

    // show player action in narrative
    appendNarrative(action, 'player-action');

    // send to engine via pywebview bridge
    const resultJSON = await window.pywebview.api.submit_action(action);
    const result = JSON.parse(resultJSON);

    // display response
    renderResponse(result);
    input.disabled = false;
    input.focus();
  }
});

// ── F-KEY OVERLAYS ──

document.addEventListener('keydown', (e) => {
  const overlays = {
    'F1': 'overlay-inventory',
    'F2': 'overlay-map',
    'F3': 'overlay-journal',
    'F4': 'overlay-feedback',
    'F5': 'overlay-debug'
  };
  if (overlays[e.key]) {
    e.preventDefault();
    toggleOverlay(overlays[e.key]);
  }
  if (e.key === 'Escape') {
    document.querySelectorAll('.overlay').forEach(
      o => o.classList.add('hidden')
    );
  }
});

function toggleOverlay(id) {
  const el = document.getElementById(id);
  el.classList.toggle('hidden');
}

// ── RENDERING ──

function renderResponse(result) {
  // narrative prose
  if (result.prose) {
    appendNarrative(result.prose, 'narrator-text');
  }

  // fragment flash
  if (result.fragments) {
    appendNarrative(result.fragments.content, 'fragment-flash');
  }

  // portraits
  if (result.portraits) {
    updatePortraits(result.portraits);
  }

  // HUD
  if (result.hud) {
    updateHUD(result.hud);
  }

  // scroll to bottom
  narrative.scrollTop = narrative.scrollHeight;
}

function appendNarrative(text, className) {
  const div = document.createElement('div');
  div.className = className;
  div.textContent = text;
  narrative.appendChild(div);
}

function updatePortraits(portraits) {
  const panel = document.getElementById('portraits');
  panel.innerHTML = '';

  for (const [npc, data] of Object.entries(portraits)) {
    const card = document.createElement('div');
    card.className = 'portrait-card';

    const img = document.createElement('img');
    img.src = typeof data === 'string' ? data : data.path;
    img.alt = npc;
    img.onerror = () => { img.style.display = 'none'; };

    const name = document.createElement('div');
    name.className = 'npc-name';
    name.textContent = npc.replace(/_/g, ' ').replace(
      /\b\w/g, l => l.toUpperCase()
    );

    const state = document.createElement('div');
    state.className = 'npc-state';
    state.textContent = typeof data === 'object'
      ? data.state || '' : '';

    card.appendChild(img);
    card.appendChild(name);
    card.appendChild(state);
    panel.appendChild(card);
  }
}

function updateHUD(hud) {
  const el = document.getElementById('hud');
  el.innerHTML = `
    <span class="hud-item">
      ♥ <span class="hud-bar"><span class="hud-bar-fill bar-health"
        style="width:${(hud.hp||0)*100}%"></span></span>
      ${(hud.hp||0).toFixed(2)}
    </span>
    <span class="hud-item">
      ⚡ <span class="hud-bar"><span class="hud-bar-fill bar-stamina"
        style="width:${(hud.stamina||0)*100}%"></span></span>
      ${(hud.stamina||0).toFixed(2)}
    </span>
    <span class="hud-item">
      ☣ <span class="hud-bar"><span class="hud-bar-fill bar-mold"
        style="width:${(hud.mold||0)*100}%"></span></span>
      ${(hud.mold||0).toFixed(2)}
    </span>
    <span class="hud-item">🗡 ${hud.weapon || 'Unarmed'}</span>
    <span class="hud-item">💰 ${hud.lei || 0}</span>
    <span class="hud-item">📍 ${hud.location || '???'}</span>
    <span class="hud-item">🕐 ${hud.time || '???'}</span>
    <span class="hud-item">📅 ${hud.days || '??'} days</span>
    <span class="hud-item">❄ ${hud.weather || ''}</span>
  `;
}

// ── INIT ──

window.addEventListener('pywebviewready', async () => {
  const stateJSON = await window.pywebview.api.get_initial_state();
  const state = JSON.parse(stateJSON);
  updateHUD(state.hud);

  appendNarrative(
    'System initialized. The Wall is active.\n' +
    'Type your actions below. [F1-F5] for panels.\n' +
    '─'.repeat(50),
    'narrator-text'
  );
});
```

```python
# engine/psyche.py — Living emotional state machine

import json
import time
from pathlib import Path
from copy import deepcopy

class Drive:
    """A single motivational drive."""
    def __init__(self, name, level=0.5, decay=0.01,
                 floor=0.0, ceiling=1.0):
        self.name = name
        self.level = level
        self.decay = decay
        self.floor = floor
        self.ceiling = ceiling

    def tick(self):
        """Decay per turn."""
        self.level = max(self.floor,
                         self.level - self.decay)

    def adjust(self, delta):
        self.level = max(self.floor,
                         min(self.ceiling,
                             self.level + delta))

    def to_dict(self):
        return {
            "level": round(self.level, 3),
            "decay_per_turn": self.decay
        }


class Emotion:
    """A single emotion with baseline and current value."""
    def __init__(self, name, baseline=0.5, current=None,
                 return_rate=0.2):
        self.name = name
        self.baseline = baseline
        self.current = current if current is not None else baseline
        self.return_rate = return_rate

    def tick(self):
        """Drift toward baseline."""
        diff = self.baseline - self.current
        self.current += diff * self.return_rate

    def spike(self, delta):
        self.current = max(0.0, min(1.0,
                                     self.current + delta))

    def to_dict(self):
        return {
            "baseline": round(self.baseline, 3),
            "current": round(self.current, 3)
        }


class Commitment:
    """An active goal with intensity and frustration tracking."""
    def __init__(self, goal, intensity=0.5):
        self.goal = goal
        self.intensity = intensity
        self.blocked_streak = 0
        self.low_turns = 0
        self.user_conflict = 0

    def block(self):
        self.blocked_streak += 1
        if self.blocked_streak >= 3:
            self.intensity = max(0.0,
                                  self.intensity - 0.05)

    def advance(self):
        self.blocked_streak = 0
        self.intensity = min(1.0,
                              self.intensity + 0.03)

    def tick(self):
        if self.intensity < 0.2:
            self.low_turns += 1
        else:
            self.low_turns = 0

    @property
    def should_abandon(self):
        return self.low_turns >= 5

    def to_dict(self):
        return {
            "goal": self.goal,
            "intensity": round(self.intensity, 3),
            "_blocked_streak": self.blocked_streak,
            "_low_turns": self.low_turns,
            "_user_conflict": self.user_conflict
        }


class Psyche:
    """
    Complete psychological state for one character.
    Drives + Emotions + Commitments + Appraisal.
    Ticks every turn. Serializes to/from JSON.
    """

    def __init__(self, character_id, data=None):
        self.character_id = character_id
        self.drives = {}
        self.emotions = {}
        self.commitments = []
        self.appraisal = ""
        self.turn_count = 0

        if data:
            self.load(data)

    def load(self, data):
        """Initialize from JSON dict."""
        for name, d in data.get("drives", {}).items():
            self.drives[name] = Drive(
                name,
                level=d.get("level", 0.5),
                decay=d.get("decay_per_turn", 0.01)
            )

        emo_data = data.get("emotions", {})
        return_rate = emo_data.get("return_rate", 0.2)
        for name in emo_data.get("baseline", {}):
            self.emotions[name] = Emotion(
                name,
                baseline=emo_data["baseline"][name],
                current=emo_data.get("current", {}).get(
                    name, emo_data["baseline"][name]
                ),
                return_rate=return_rate
            )

        for c in data.get("commitments", []):
            self.commitments.append(Commitment(
                goal=c["goal"],
                intensity=c.get("intensity", 0.5)
            ))

        self.appraisal = data.get("appraisal", "")

    def tick(self):
        """Advance one turn — decay drives, drift emotions,
        check commitments."""
        self.turn_count += 1

        for drive in self.drives.values():
            drive.tick()

        for emotion in self.emotions.values():
            emotion.tick()

        for commitment in self.commitments:
            commitment.tick()

        # auto-abandon dead commitments
        self.commitments = [
            c for c in self.commitments
            if not c.should_abandon
        ]

    def get_dominant_drive(self):
        """Which drive is screaming loudest (lowest level = most deprived)."""
        if not self.drives:
            return None
        return min(self.drives.values(),
                   key=lambda d: d.level)

    def get_emotional_state(self):
        """Returns the strongest current emotion."""
        if not self.emotions:
            return None
        return max(self.emotions.values(),
                   key=lambda e: abs(e.current - 0.5))

    def get_active_commitments(self):
        """Returns commitments sorted by intensity."""
        return sorted(self.commitments,
                      key=lambda c: c.intensity,
                      reverse=True)

    def generate_appraisal_prompt(self, scene_context):
        """
        Generates a prompt for the GM to update the
        character's appraisal of the current situation.
        The GM fills this in and it becomes part of the
        narrator's NPC direction.
        """
        dominant = self.get_dominant_drive()
        emotional = self.get_emotional_state()
        top_goals = self.get_active_commitments()[:3]

        return {
            "character": self.character_id,
            "dominant_drive": dominant.name if dominant else None,
            "drive_level": dominant.level if dominant else None,
            "emotional_state": {
                emotional.name: round(emotional.current, 2)
            } if emotional else None,
            "active_goals": [c.goal for c in top_goals],
            "scene": scene_context,
            "instruction": (
                "Given this character's current psychological "
                "state and the scene context, write a 1-2 sentence "
                "internal appraisal — what are they thinking/feeling "
                "RIGHT NOW? This shapes their next behavior."
            )
        }

    def to_dict(self):
        return {
            "drives": {
                name: d.to_dict()
                for name, d in self.drives.items()
            },
            "emotions": {
                "baseline": {
                    name: e.baseline
                    for name, e in self.emotions.items()
                },
                "current": {
                    name: round(e.current, 3)
                    for name, e in self.emotions.items()
                },
                "return_rate": next(iter(
                    self.emotions.values()
                )).return_rate if self.emotions else 0.2
            },
            "commitments": [c.to_dict() for c in self.commitments],
            "appraisal": self.appraisal
        }

    def save(self):
        path = Path("data/psyche") / f"{self.character_id}.json"
        path.write_text(json.dumps(self.to_dict(), indent=2))

    @classmethod
    def from_file(cls, character_id):
        path = Path("data/psyche") / f"{character_id}.json"
        if path.exists():
            data = json.loads(path.read_text())
            return cls(character_id, data)
        return cls(character_id)


class PsycheManager:
    """
    Manages all active psyche instances.
    Ticks all of them per turn.
    """

    def __init__(self):
        self.active = {}  # character_id → Psyche

    def load_for_scene(self, npc_ids):
        """Load psyche states for NPCs present in scene."""
        for npc_id in npc_ids:
            if npc_id not in self.active:
                self.active[npc_id] = Psyche.from_file(npc_id)

    def unload_absent(self, present_ids):
        """Save and unload NPCs no longer in scene."""
        to_remove = [
            npc_id for npc_id in self.active
            if npc_id not in present_ids
        ]
        for npc_id in to_remove:
            self.active[npc_id].save()
            del self.active[npc_id]

    def tick_all(self):
        """Advance all active psyches one turn."""
        for psyche in self.active.values():
            psyche.tick()

    def get_psyche(self, npc_id) -> Psyche:
        return self.active.get(npc_id)

    def get_all_summaries(self):
        """For the GM — quick read of everyone's state."""
        return {
            npc_id: {
                "dominant_drive": (
                    p.get_dominant_drive().name
                    if p.get_dominant_drive() else None
                ),
                "drive_deprivation": (
                    round(p.get_dominant_drive().level, 2)
                    if p.get_dominant_drive() else None
                ),
                "emotional_peak": (
                    p.get_emotional_state().name
                    if p.get_emotional_state() else None
                ),
                "top_goal": (
                    p.get_active_commitments()[0].goal
                    if p.get_active_commitments() else None
                )
            }
            for npc_id, p in self.active.items()
        }

    def save_all(self):
        for psyche in self.active.values():
            psyche.save()
```

```python
# engine/memory.py — Three-tier memory system

import json
import time
from pathlib import Path
from collections import deque

class MemoryEntry:
    """A single memory."""
    def __init__(self, content, memory_type, importance=0.5,
                 emotional_valence=0.0, tags=None,
                 timestamp=None, turn=None):
        self.content = content
        self.type = memory_type  # episodic, semantic, emotional
        self.importance = importance
        self.emotional_valence = emotional_valence  # -1 to 1
        self.tags = tags or []
        self.timestamp = timestamp or time.time()
        self.turn = turn or 0
        self.access_count = 0
        self.last_accessed = self.timestamp

    def access(self):
        self.access_count += 1
        self.last_accessed = time.time()

    @property
    def relevance_score(self):
        """
        How relevant is this memory right now?
        Importance + recency + emotional intensity + access frequency.
        """
        age = time.time() - self.last_accessed
        recency = max(0, 1.0 - (age / 86400))  # decays over 24hrs real time
        emotion_weight = abs(self.emotional_valence)
        access_weight = min(1.0, self.access_count * 0.1)

        return (
            self.importance * 0.4 +
            recency * 0.25 +
            emotion_weight * 0.2 +
            access_weight * 0.15
        )

    def to_dict(self):
        return {
            "content": self.content,
            "type": self.type,
            "importance": self.importance,
            "emotional_valence": self.emotional_valence,
            "tags": self.tags,
            "timestamp": self.timestamp,
            "turn": self.turn,
            "access_count": self.access_count,
            "last_accessed": self.last_accessed
        }

    @classmethod
    def from_dict(cls, data):
        entry = cls(
            content=data["content"],
            memory_type=data["type"],
            importance=data.get("importance", 0.5),
            emotional_valence=data.get("emotional_valence", 0.0),
            tags=data.get("tags", []),
            timestamp=data.get("timestamp"),
            turn=data.get("turn")
        )
        entry.access_count = data.get("access_count", 0)
        entry.last_accessed = data.get("last_accessed",
                                        entry.timestamp)
        return entry


class MemoryBank:
    """
    Three-tier memory system:
      EPISODIC  — scene summaries, what happened
      SEMANTIC  — facts, relationships, world knowledge
      EMOTIONAL — emotional impressions of people/places

    Working memory holds the most recent/relevant subset
    for injection into the narrator's context.
    """

    def __init__(self, max_working=20,
                 archive_threshold=100):
        self.episodic = []
        self.semantic = []
        self.emotional = []
        self.working_memory = deque(maxlen=max_working)
        self.archive_threshold = archive_threshold
        self.data_dir = Path("data/memory")
        self.data_dir.mkdir(parents=True, exist_ok=True)
        self.load()

    def add(self, content, memory_type, importance=0.5,
            emotional_valence=0.0, tags=None, turn=0):
        """Add a new memory."""
        entry = MemoryEntry(
            content=content,
            memory_type=memory_type,
            importance=importance,
            emotional_valence=emotional_valence,
            tags=tags,
            turn=turn
        )

        bank = getattr(self, memory_type)
        bank.append(entry)

        # auto-promote high importance to working memory
        if importance >= 0.7:
            self.working_memory.append(entry)

        # archive check
        if len(bank) > self.archive_threshold:
            self._archive(memory_type)

    def recall(self, query_tags=None, memory_type=None,
               top_k=10):
        """
        Retrieve most relevant memories.
        Optionally filter by tags and type.
        """
        pool = []
        if memory_type:
            pool = getattr(self, memory_type, [])
        else:
            pool = self.episodic + self.semantic + self.emotional

        if query_tags:
            pool = [
                m for m in pool
                if any(t in m.tags for t in query_tags)
            ]

        # sort by relevance
        ranked = sorted(pool,
                        key=lambda m: m.relevance_score,
                        reverse=True)

        # mark as accessed
        results = ranked[:top_k]
        for m in results:
            m.access()

        return results

    def get_working_memory(self):
        """
        Returns working memory as a formatted string
        for injection into narrator context.
        """
        if not self.working_memory:
            return ""

        lines = ["[WORKING MEMORY — what you remember:]"]
        for m in self.working_memory:
            prefix = {
                "episodic": "EVENT",
                "semantic": "FACT",
                "emotional": "FEELING"
            }.get(m.type, "MEMORY")
            lines.append(f"  [{prefix}] {m.content}")

        return "\n".join(lines)

    def refresh_working_memory(self, scene_tags=None):
        """
        Rebuild working memory from all banks based
        on current scene relevance.
        """
        self.working_memory.clear()

        # get top relevant from each bank
        episodic = self.recall(
            query_tags=scene_tags,
            memory_type="episodic", top_k=8
        )
        semantic = self.recall(
            query_tags=scene_tags,
            memory_type="semantic", top_k=8
        )
        emotional = self.recall(
            query_tags=scene_tags,
            memory_type="emotional", top_k=4
        )

        combined = episodic + semantic + emotional
        combined.sort(key=lambda m: m.relevance_score,
                      reverse=True)

        for m in combined[:20]:
            self.working_memory.append(m)

    def summarize_scene(self, scene_text, gm_client,
                        turn_number):
        """
        Ask the GM to summarize a completed scene into
        memory entries. Returns structured memories.
        This is where raw narrative becomes compressed
        knowledge.
        """
        prompt = {
            "instruction": (
                "Summarize this scene into memory entries. "
                "Extract:\n"
                "1. EPISODIC: what happened (1-2 sentences)\n"
                "2. SEMANTIC: any facts learned (list)\n"
                "3. EMOTIONAL: how the PC felt about people/"
                "places encountered (list)\n"
                "Rate each entry's importance 0.0-1.0.\n"
                "Output JSON."
            ),
            "scene_text": scene_text,
            "turn": turn_number
        }
        return prompt  # GM processes this async

    def ingest_summary(self, summary_data, turn):
        """Process GM's scene summary into memory entries."""
        for ep in summary_data.get("episodic", []):
            self.add(
                content=ep["content"],
                memory_type="episodic",
                importance=ep.get("importance", 0.5),
                tags=ep.get("tags", []),
                turn=turn
            )

        for sem in summary_data.get("semantic", []):
            # semantic memories: check for duplicates/updates
            existing = [
                m for m in self.semantic
                if any(t in m.tags for t in sem.get("tags", []))
            ]
            if existing:
                # update existing fact rather than duplicate
                existing[0].content = sem["content"]
                existing[0].importance = max(
                    existing[0].importance,
                    sem.get("importance", 0.5)
                )
            else:
                self.add(
                    content=sem["content"],
                    memory_type="semantic",
                    importance=sem.get("importance", 0.5),
                    tags=sem.get("tags", []),
                    turn=turn
                )

        for emo in summary_data.get("emotional", []):
            self.add(
                content=emo["content"],
                memory_type="emotional",
                importance=emo.get("importance", 0.5),
                emotional_valence=emo.get("valence", 0.0),
                tags=emo.get("tags", []),
                turn=turn
            )

    def _archive(self, memory_type):
        """
        Compress oldest, least relevant memories.
        Keep the important ones, summarize the rest into
        a single compressed entry.
        """
        bank = getattr(self, memory_type)

        # sort by relevance
        bank.sort(key=lambda m: m.relevance_score)

        # bottom half gets compressed
        split = len(bank) // 2
        to_archive = bank[:split]
        to_keep = bank[split:]

        # compress archived into single entry
        compressed_content = " | ".join(
            m.content for m in to_archive
        )
        archive_entry = MemoryEntry(
            content=f"[COMPRESSED] {compressed_content[:500]}",
            memory_type=memory_type,
            importance=0.3,
            tags=["archived"]
        )

        # save archive to disk
        archive_path = (
            self.data_dir / "archive" /
            f"{memory_type}_{int(time.time())}.json"
        )
        archive_path.parent.mkdir(parents=True, exist_ok=True)
        archive_path.write_text(json.dumps(
            [m.to_dict() for m in to_archive], indent=2
        ))

        # replace bank with kept + compressed
        setattr(self, memory_type, to_keep + [archive_entry])

    def save(self):
        for mem_type in ["episodic", "semantic", "emotional"]:
            bank = getattr(self, mem_type)
            path = self.data_dir / f"{mem_type}.json"
            path.write_text(json.dumps(
                [m.to_dict() for m in bank], indent=2
            ))

    def load(self):
        for mem_type in ["episodic", "semantic", "emotional"]:
            path = self.data_dir / f"{mem_type}.json"
            if path.exists():
                data = json.loads(path.read_text())
                bank = [MemoryEntry.from_dict(d) for d in data]
                setattr(self, mem_type, bank)

    def get_token_estimate(self):
        """Rough token count for budgeting."""
        total_chars = sum(
            len(m.content)
            for m in list(self.working_memory)
        )
        return total_chars // 4  # rough token estimate
```

```python
class PresetManager:
    def __init__(self):
        self.presets_dir = Path("data/presets")
        self.presets_dir.mkdir(parents=True, exist_ok=True)
        self.active_preset = "balanced"
        self.presets = {}
        self._init_defaults()
        self._load_custom()

    def _init_defaults(self):
        for name, preset in DEFAULT_PRESETS.items():
            path = self.presets_dir / f"{name}.yaml"
            if not path.exists():
                yaml.dump(preset, path.open('w'))
            self.presets[name] = preset

    def _load_custom(self):
        for path in self.presets_dir.glob("*.yaml"):
            name = path.stem
            if name not in self.presets:
                self.presets[name] = yaml.safe_load(
                    path.read_text()
                )

    def get_active(self):
        return self.presets.get(
            self.active_preset,
            DEFAULT_PRESETS["balanced"]
        )

    def set_active(self, name):
        if name in self.presets:
            self.active_preset = name
            return True
        return False

    def create_preset(self, name, params):
        self.presets[name] = params
        path = self.presets_dir / f"{name}.yaml"
        yaml.dump(params, path.open('w'))

    def list_presets(self):
        return {
            name: p.get("description", "")
            for name, p in self.presets.items()
        }

    def get_sampling_params(self):
        """Returns params formatted for API call."""
        preset = self.get_active()
        return {
            "temperature": preset.get("temperature", 0.8),
            "top_p": preset.get("top_p", 0.95),
            "top_k": preset.get("top_k", 40),
            "max_tokens": preset.get("max_tokens", 1500)
        }
```

```python
# engine/commands.py — Slash command router

import json
import shlex
from dataclasses import dataclass
from typing import Optional, Callable

@dataclass
class CommandResult:
    """What a command returns to the UI."""
    success: bool
    message: str
    data: Optional[dict] = None
    suppress_turn: bool = False  # if True, don't run normal turn
    inject_to_gm: Optional[str] = None  # pass to GM as context


class CommandRouter:
    """
    Handles all /slash commands.
    Commands are meta-actions that control the engine
    rather than playing the game.
    """

    def __init__(self, wall, psyche_mgr, memory,
                 presets, mode_mgr):
        self.wall = wall
        self.psyche = psyche_mgr
        self.memory = memory
        self.presets = presets
        self.modes = mode_mgr
        self.commands = self._register_commands()

    def _register_commands(self):
        return {
            # ── GAME CONTROL ──
            "/save": self.cmd_save,
            "/load": self.cmd_load,
            "/mode": self.cmd_mode,
            "/preset": self.cmd_preset,
            "/time": self.cmd_time,
            "/status": self.cmd_status,

            # ── GM SIGNALING ──
            "/spawn": self.cmd_spawn,
            "/encounter": self.cmd_encounter,
            "/scenario": self.cmd_scenario,
            "/event": self.cmd_event,

            # ── DYNAMIC GENERATION ──
            "/create": self.cmd_create,
            "/generate": self.cmd_generate,

            # ── INFORMATION ──
            "/psyche": self.cmd_psyche,
            "/memory": self.cmd_memory,
            "/map": self.cmd_map,
            "/inventory": self.cmd_inventory,
            "/journal": self.cmd_journal,
            "/secrets": self.cmd_secrets,

            # ── META ──
            "/feedback": self.cmd_feedback,
            "/correction": self.cmd_correction,
            "/note": self.cmd_note,
            "/help": self.cmd_help,
            "/undo": self.cmd_undo,
            "/retry": self.cmd_retry,
            "/rewrite": self.cmd_rewrite,

            # ── DEBUG ──
            "/debug": self.cmd_debug,
            "/vault": self.cmd_vault,
            "/state": self.cmd_state,
            "/force": self.cmd_force,
        }

    def is_command(self, input_text):
        return input_text.strip().startswith("/")

    async def execute(self, input_text):
        """Parse and execute a slash command."""
        parts = shlex.split(input_text.strip())
        cmd = parts[0].lower()
        args = parts[1:]

        handler = self.commands.get(cmd)
        if not handler:
            return CommandResult(
                success=False,
                message=f"Unknown command: {cmd}. Type /help"
            )

        try:
            return await handler(args)
        except Exception as e:
            return CommandResult(
                success=False,
                message=f"Error executing {cmd}: {str(e)}"
            )

    # ════════════════════════════════════════════
    # GAME CONTROL
    # ════════════════════════════════════════════

    async def cmd_save(self, args):
        """  /save [slot_name]  """
        slot = args[0] if args else "quicksave"
        self.wall.state.save_game(slot)
        self.psyche.save_all()
        self.memory.save()
        return CommandResult(
            success=True,
            message=f"✓ Saved to slot: {slot}",
            suppress_turn=True
        )

    async def cmd_load(self, args):
        """  /load [slot_name]  """
        slot = args[0] if args else "quicksave"
        self.wall.state.load_save(slot)
        return CommandResult(
            success=True,
            message=f"✓ Loaded from slot: {slot}",
            suppress_turn=True
        )

    async def cmd_mode(self, args):
        """
        /mode game    — full dual-brain with Wall
        /mode story   — narrator only, no GM, no Wall
        /mode freeform — no mechanics, pure RP
        """
        if not args:
            current = self.modes.current_mode
            return CommandResult(
                success=True,
                message=(
                    f"Current mode: {current}\n"
                    f"Available: game, story, freeform"
                ),
                suppress_turn=True
            )
        mode = args[0].lower()
        success = self.modes.set_mode(mode)
        if success:
            return CommandResult(
                success=True,
                message=f"✓ Mode switched to: {mode}",
                suppress_turn=True
            )
        return CommandResult(
            success=False,
            message=f"Unknown mode: {mode}"
        )

    async def cmd_preset(self, args):
        """  /preset [name] or /preset list  """
        if not args or args[0] == "list":
            presets = self.presets.list_presets()
            lines = [f"  {'*' if name == self.presets.active_preset else ' '} "
                     f"{name}: {desc}"
                     for name, desc in presets.items()]
            return CommandResult(
                success=True,
                message="Presets:\n" + "\n".join(lines),
                suppress_turn=True
            )
        name = args[0]
        if self.presets.set_active(name):
            return CommandResult(
                success=True,
                message=f"✓ Preset: {name}",
                suppress_turn=True
            )
        return CommandResult(
            success=False,
            message=f"Unknown preset: {name}"
        )

    async def cmd_time(self, args):
        """  /time — show current time state  """
        w = self.wall.state.world
        cal = w.get("calendar", {})
        return CommandResult(
            success=True,
            message=(
                f"📅 Day {18 - cal.get('days_to_ceremony', 18)} "
                f"| {cal.get('time_of_day', '???')} "
                f"| {cal.get('weather', '???')}\n"
                f"   {cal.get('days_to_ceremony', '??')} days "
                f"to ceremony"
            ),
            suppress_turn=True
        )

    async def cmd_status(self, args):
        """  /status — full PC status dump  """
        pc = self.wall.state.pc
        vitals = pc.get("vitals", {})
        stats = pc.get("stats", {})
        return CommandResult(
            success=True,
            message=(
                f"═══ PC STATUS ═══\n"
                f"HP: {vitals.get('health', {}).get('current', '?')}\n"
                f"STA: {vitals.get('stamina', {}).get('current', '?')}\n"
                f"MOLD: {vitals.get('mold_exposure', {}).get('level', '?')}\n"
                f"───\n"
                f"STR: {stats.get('strength', '?')}  "
                f"SPD: {stats.get('speed', '?')}\n"
                f"PER: {stats.get('perception', '?')}  "
                f"WIL: {stats.get('willpower', '?')}\n"
                f"CHA: {stats.get('charisma', '?')}  "
                f"KNO: {stats.get('knowledge', '?')}\n"
            ),
            suppress_turn=True
        )

    # ════════════════════════════════════════════
    # GM SIGNALING
    # ════════════════════════════════════════════

    async def cmd_spawn(self, args):
        """
        /spawn lycan 3          — spawn 3 lycans
        /spawn moroaica         — spawn 1 moroaica
        /spawn soldat heavy     — spawn heavy soldat variant
        Signal GM to create enemies in the current scene.
        """
        if not args:
            return CommandResult(
                success=False,
                message="Usage: /spawn [type] [count] [variant]"
            )
        enemy_type = args[0]
        count = int(args[1]) if len(args) > 1 else 1
        variant = args[2] if len(args) > 2 else "standard"

        return CommandResult(
            success=True,
            message=f"⚔ Signaling GM: spawn {count}x "
                    f"{enemy_type} ({variant})",
            suppress_turn=False,
            inject_to_gm=json.dumps({
                "command": "spawn",
                "enemy_type": enemy_type,
                "count": count,
                "variant": variant,
                "location": self.wall.state.world
                    .get("calendar", {})
            })
        )

    async def cmd_encounter(self, args):
        """
        /encounter combat       — force a combat encounter
        /encounter puzzle       — force a puzzle encounter
        /encounter social [npc] — force a social encounter
        /encounter random       — let GM decide
        """
        if not args:
            return CommandResult(
                success=False,
                message="Usage: /encounter [type] [details]"
            )
        enc_type = args[0]
        details = " ".join(args[1:]) if len(args) > 1 else ""

        return CommandResult(
            success=True,
            message=f"⚔ Signaling GM: generate {enc_type} "
                    f"encounter" +
                    (f" ({details})" if details else ""),
            suppress_turn=False,
            inject_to_gm=json.dumps({
                "command": "generate_encounter",
                "type": enc_type,
                "details": details
            })
        )

    async def cmd_scenario(self, args):
        """
        /scenario "The Lycan pack has breached the east fence"
        Signal GM to weave a scenario into the world.
        """
        if not args:
            return CommandResult(
                success=False,
                message='Usage: /scenario "description"'
            )
        description = " ".join(args)

        return CommandResult(
            success=True,
            message=f"📋 Signaling GM: integrate scenario",
            suppress_turn=False,
            inject_to_gm=json.dumps({
                "command": "integrate_scenario",
                "description": description
            })
        )

    async def cmd_event(self, args):
        """
        /event trigger "lycan_aggression >= 0.5"
        /event fire "first_lycan_village_attack"
        /event list
        Manage the event queue.
        """
        if not args:
            return CommandResult(
                success=False,
                message="Usage: /event [trigger|fire|list] [details]"
            )
        sub = args[0]
        if sub == "list":
            events = self.wall.state.world.get("event_queue", [])
            lines = [
                f"  • {e.get('trigger', '???')}: "
                f"{e.get('event', '???')}"
                for e in events
            ]
            return CommandResult(
                success=True,
                message="Event Queue:\n" + "\n".join(
                    lines or ["  (empty)"]
                ),
                suppress_turn=True
            )
        elif sub == "fire":
            event_id = " ".join(args[1:])
            return CommandResult(
                success=True,
                message=f"⚡ Firing event: {event_id}",
                inject_to_gm=json.dumps({
                    "command": "fire_event",
                    "event_id": event_id
                })
            )

        return CommandResult(
            success=False,
            message="Usage: /event [trigger|fire|list]"
        )

    # ════════════════════════════════════════════

    async def cmd_create(self, args):
        """

        /create item "rusted cavalry saber, found in the mill"
        /create location "hidden root cellar beneath the church"

            "GM": ["/spawn", "/encounter", "/scenario", "/event"],
            "CREATE": ["/create", "/generate"],

                     "/help", "/undo", "/retry", "/rewrite"],
            "DEBUG": ["/debug", "/vault", "/state", "/force"]

        lines = ["═══ COMMANDS ═══"]

            self.wall.state.chat_history.pop()
            self.wall.state.chat_history.pop()

                success=True,
                message="✓ Last exchange undone",
                suppress_turn=True

        return CommandResult(
            success=False,
            message="Nothing to undo"
        )

        """Regenerate last response."""
        if self.wall.state.chat_history:
            self.wall.state.chat_history.pop()  # remove last response
            return CommandResult(
                success=True,
                message="✓ Regenerating...",
                suppress_turn=False
                # the UI resends the last player message
            )
        return CommandResult(
            success=False,
            message="Nothing to retry"
        )

    async def cmd_rewrite(self, args):
        """  /rewrite [instructions] — regenerate with guidance  """
        instructions = " ".join(args) if args else ""
        if self.wall.state.chat_history:
            self.wall.state.chat_history.pop()
            return CommandResult(
                success=True,
                message="✓ Rewriting...",
                suppress_turn=False,
                inject_to_gm=json.dumps({
                    "command": "rewrite",

                })

        return CommandResult(
            success=False,
            message="Nothing to rewrite"
        )

        if target == "pc":
            data = self.wall.state.pc
        elif target == "world":
            data = self.wall.state.world
        else:
            data = {
                "pc": self.wall.state.pc,
                "world": self.wall.state.world
            }
        return CommandResult(
            success=True,
            message=json.dumps(data, indent=2)[:3000],
            suppress_turn=True
        )

    async def cmd_force(self, args):
        """
        /force [state_path] [value]
        e.g. /force world.calendar.days_to_ceremony 10
        e.g. /force pc.vitals.health.current 1.0
        DEBUG: force a state value. Use carefully.
        """
        if len(args) < 2:
            return CommandResult(
                success=False,
                message="Usage: /force [path] [value]"
            )
        path = args[0].split(".")
        value = args[1]

        # try to parse value type
        try:
            value = json.loads(value)
        except json.JSONDecodeError:
            pass  # keep as string

        # navigate to target
        target = {"pc": self.wall.state.pc,
                  "world": self.wall.state.world}
        obj = target
        for key in path[:-1]:
            if isinstance(obj, dict):
                obj = obj.get(key, {})

        if isinstance(obj, dict):
            obj[path[-1]] = value
            return CommandResult(
                success=True,
                message=f"✓ Forced {args[0]} = {value}",
                suppress_turn=True
            )
        return CommandResult(
            success=False,
            message=f"Invalid path: {args[0]}"
        )
```

### 5. MODE SWITCHER — Game / Story / Freeform

# engine/modes.py — Game mode management

class ModeManager:
    """
    Three modes of operation:

    GAME:     Full dual-brain. Wall active. GM does mechanics,
              gating, encounters. The full sandbox experience.

    STORY:    Narrator only. No GM, no Wall, no mechanics.
              All character cards loaded in FULL (no public/
              private split). No HUD. No state tracking. Just
              collaborative storytelling with the world and
              characters we built. SillyTavern-style RP.

    FREEFORM: Narrator only, NO cards auto-loaded. The player
              manually controls what's in context. Pure blank
              canvas. For testing voices, writing scenes, or
              using the app as a general RP tool outside the
              Village sandbox.
    """

    MODES = {
        "game": {
            "wall_active": True,
            "gm_active": True,
            "hud_active": True,
            "mechanics_active": True,
            "card_split": True,  # public/private enforced
            "psyche_active": True,
            "memory_active": True,
            "narrator_system": "game_narrator",
        },
        "story": {
            "wall_active": False,
            "gm_active": False,
            "hud_active": False,
            "mechanics_active": False,
            "card_split": False,  # full cards loaded
            "psyche_active": True,  # still track emotions
            "memory_active": True,  # still track memory
            "narrator_system": "story_narrator",
        },
        "freeform": {
            "wall_active": False,
            "gm_active": False,
            "hud_active": False,
            "mechanics_active": False,
            "card_split": False,
            "psyche_active": False,
            "memory_active": False,
            "narrator_system": "freeform_narrator",
        }
    }

```python
# engine/wall.py — Updated process_turn

class Wall:

    def __init__(self, config):
        self.gm = GameMaster(config)
        self.narrator = Narrator(config)
        self.state = StateManager()
        self.psyche_mgr = PsycheManager()
        self.memory = MemoryBank()
        self.presets = PresetManager()
        self.modes = ModeManager()
        self.commands = CommandRouter(
            wall=self,
            psyche_mgr=self.psyche_mgr,
            memory=self.memory,
            presets=self.presets,
            mode_mgr=self.modes
        )
        self.revelation_log = []
        self._feedback_queue = []
        self.turn_count = 0

    async def process_turn(self, player_input: str) -> dict:
        """
        Routes input through the appropriate pipeline
        based on current mode.
        """

        # ── SLASH COMMANDS (all modes) ──
        if self.commands.is_command(player_input):
            result = await self.commands.execute(player_input)
            if result.suppress_turn:
                return {
                    "prose": result.message,
                    "hud": None,
                    "portraits": None,
                    "command_result": True,
                    "panel": result.data.get("panel")
                        if result.data else None
                }
            # command wants to also run a turn
            # (e.g. /spawn injects to GM then continues)
            if result.inject_to_gm:
                player_input = result.inject_to_gm

        self.turn_count += 1
        mode = self.modes.get_config()

        # ── ROUTE BY MODE ──
        if mode["wall_active"]:
            return await self._game_turn(player_input)
        elif mode["narrator_system"] == "story_narrator":
            return await self._story_turn(player_input)
        else:
            return await self._freeform_turn(player_input)

    async def _game_turn(self, player_input):
        """Full dual-brain pipeline. The Wall is active."""

        # 1. Collect psyche summaries for present NPCs
        present_npcs = self._get_present_npcs()
        self.psyche_mgr.load_for_scene(present_npcs)

        psyche_summaries = self.psyche_mgr.get_all_summaries()

        # 2. Collect relevant memories
        scene_tags = self._get_scene_tags()
        self.memory.refresh_working_memory(scene_tags)
        working_mem = self.memory.get_working_memory()

        # 3. Collect feedback queue
        feedback = list(self._feedback_queue)
        self._feedback_queue.clear()

        # 4. GM evaluates
        briefing = await self.gm.evaluate(
            player_input=player_input,
            pc_state=self.state.pc,
            world_state=self.state.world,
            vault=self.state.vault,
            fragment_map=self.state.fragments,
            revelation_log=self.revelation_log,
            psyche_summaries=psyche_summaries,
            working_memory=working_mem,
            feedback=feedback
        )

        # 5. Apply state updates
        self.state.apply_updates(briefing["state_updates"])

        # 6. Update psyche states from GM direction
        if "psyche_updates" in briefing:
            for npc_id, updates in briefing["psyche_updates"].items():
                psyche = self.psyche_mgr.get_psyche(npc_id)
                if psyche:
                    for drive, delta in updates.get("drives", {}).items():
                        if drive in psyche.drives:
                            psyche.drives[drive].adjust(delta)
                    for emotion, delta in updates.get("emotions", {}).items():
                        if emotion in psyche.emotions:
                            psyche.emotions[emotion].spike(delta)
                    for commit in updates.get("new_commitments", []):
                        psyche.commitments.append(
                            Commitment(
                                goal=commit["goal"],
                                intensity=commit.get("intensity", 0.5)
                            )
                        )
                    if "appraisal" in updates:
                        psyche.appraisal = updates["appraisal"]

        # 7. Tick all psyches (drives decay, emotions drift)
        self.psyche_mgr.tick_all()

        # 8. Track revelations
        newly_revealed = briefing["information_release"].get(
            "reveal_this_turn", []
        )
        self.revelation_log.extend(newly_revealed)

        # 9. Build narrator context (THE WALL)
        narrator_context = self.build_narrator_context(
            briefing=briefing,
            npcs_present=briefing["scene_context"]["npcs_present"],
            working_memory=working_mem,
            feedback=feedback
        )

        # 10. Get sampling params from active preset
        sampling = self.presets.get_sampling_params()

        # 11. Narrator generates
        prose = await self.narrator.generate(
            context=narrator_context,
            player_input=player_input,
            sampling_params=sampling
        )

        # 12. Memory: summarize this exchange
        if self.modes.memory_active:
            scene_text = f"Player: {player_input}\n\nNarrator: {prose}"
            summary_prompt = self.memory.summarize_scene(
                scene_text=scene_text,
                gm_client=self.gm,
                turn_number=self.turn_count
            )
            # quick summary via GM
            summary_data = await self.gm.quick_summarize(
                summary_prompt
            )
            if summary_data:
                self.memory.ingest_summary(
                    summary_data, self.turn_count
                )

        # 13. Save psyche states
        self.psyche_mgr.save_all()

        # 14. Assemble display
        return {
            "prose": prose,
            "hud": briefing["hud_data"],
            "portraits": self.get_portraits(
                npcs=briefing["scene_context"]["npcs_present"],
                states=briefing.get("npc_states", {})
            ),
            "fragments": briefing["information_release"].get(
                "fragment_trigger", None
            ),
            "command_result": False
        }

    async def _story_turn(self, player_input):
        """
        Story mode. No GM, no Wall, no mechanics.
        Full character cards. Narrator does everything.
        Psyche and memory still active for tracking.
        """

        present_npcs = self._get_present_npcs()

        # psyche still ticks
        if self.modes.psyche_active:
            self.psyche_mgr.load_for_scene(present_npcs)
            self.psyche_mgr.tick_all()

        # memory still refreshes
        working_mem = ""
        if self.modes.memory_active:
            scene_tags = self._get_scene_tags()
            self.memory.refresh_working_memory(scene_tags)
            working_mem = self.memory.get_working_memory()

        # feedback
        feedback = list(self._feedback_queue)
        self._feedback_queue.clear()

        # build FULL context (no card splitting, no gating)
        context = {
            "system": self.modes.get_narrator_prompt(),
            "world": self.state.world_public,
            "characters": {},
            "working_memory": working_mem,
            "feedback": feedback,
            "chat_history": self.state.chat_history[-30:],
            "authors_note": self.state.authors_note
        }

        # load FULL cards (not split)
        for npc_id in present_npcs:
            char_dir = Path("data/characters") / npc_id
            public = json.loads(
                (char_dir / "public.json").read_text()
            )
            private_path = char_dir / "private.json"
            if private_path.exists():
                private = json.loads(private_path.read_text())
                # merge everything
                public.update(private)
            context["characters"][npc_id] = public

        # psyche states as narrator guidance
        if self.modes.psyche_active:
            context["psyche_states"] = {
                npc_id: self.psyche_mgr.get_psyche(npc_id).to_dict()
                for npc_id in present_npcs
                if self.psyche_mgr.get_psyche(npc_id)
            }

        sampling = self.presets.get_sampling_params()
        prose = await self.narrator.generate(
            context=context,
            player_input=player_input,
            sampling_params=sampling
        )

        # memory summary
        if self.modes.memory_active:
            scene_text = f"Player: {player_input}\n\nNarrator: {prose}"
            # in story mode, narrator does its own summarizing
            summary_prompt = self.memory.summarize_scene(
                scene_text, None, self.turn_count
            )
            # use narrator for summary since no GM
            summary_data = await self.narrator.quick_task(
                json.dumps(summary_prompt)
            )
            if summary_data:
                self.memory.ingest_summary(
                    summary_data, self.turn_count
                )

        if self.modes.psyche_active:
            self.psyche_mgr.save_all()

        return {
            "prose": prose,
            "hud": None,  # no HUD in story mode
            "portraits": self.get_portraits(
                npcs=present_npcs,
                states={}
            ),
            "fragments": None,
            "command_result": False
        }

    async def _freeform_turn(self, player_input):
        """
        Freeform mode. Pure narrator. No cards, no state,
        no tracking. Just vibes.
        """
        context = {
            "system": self.modes.get_narrator_prompt(),
            "chat_history": self.state.chat_history[-40:],
            "authors_note": self.state.authors_note
        }

        sampling = self.presets.get_sampling_params()
        prose = await self.narrator.generate(
            context=context,
            player_input=player_input,
            sampling_params=sampling
        )

        return {
            "prose": prose,
            "hud": None,
            "portraits": None,
            "fragments": None,
            "command_result": False
        }

    def build_narrator_context(self, briefing, npcs_present,
                                working_memory="", feedback=None):
        """
        THE WALL — game mode only.
        Assembles ONLY what the narrator is allowed to see.
        """
        context = {
            "system": self.modes.get_narrator_prompt(),
            "world": self.state.world_public,
            "characters": {},
            "briefing": {
                "scene_context": briefing["scene_context"],
                "action_resolution": briefing["action_resolution"],
                "npc_direction": briefing["npc_direction"],
                "revealed_info": self.revelation_log,
            },
            "working_memory": working_memory,
            "feedback": feedback or [],
            "chat_history": self.state.chat_history[-20:],
            "authors_note": self.state.authors_note
        }

        # GATED character cards
        for npc in npcs_present:
            context["characters"][npc] = (
                self.state.get_narrator_card(
                    npc, self.revelation_log
                )
            )

        # psyche summaries (surface level for narrator)
        psyche_for_narrator = {}
        for npc in npcs_present:
            p = self.psyche_mgr.get_psyche(npc)
            if p and p.appraisal:
                psyche_for_narrator[npc] = {
                    "current_appraisal": p.appraisal,
                    "emotional_state": {
                        name: round(e.current, 2)
                        for name, e in p.emotions.items()
                    }
                }
        if psyche_for_narrator:
            context["npc_psychology"] = psyche_for_narrator

        return context

    def _get_present_npcs(self):
        """Determine who's in the current scene."""
        # from world state tracking
        location = self.state.world.get("faction_state", {})
        # simplified — in practice this reads from the
        # last briefing or scene state
        return self.state.world.get(
            "_current_scene_npcs", []
        )

    def _get_scene_tags(self):
        """Tags for memory retrieval based on current scene."""
        tags = []
        loc = self.state.pc.get("location", {})
        tags.append(loc.get("current", ""))
        tags.append(loc.get("sub_location", ""))
        npcs = self._get_present_npcs()
        tags.extend(npcs)
        return [t for t in tags if t]
```

```python
    def submit_action(self, player_input: str) -> str:
        loop = asyncio.new_event_loop()
        result = loop.run_until_complete(
            self.wall.process_turn(player_input)

        loop.close()

                "content": player_input
            })
            self.wall.state.chat_history.append({
                "role": "assistant",

            })

            "episodic": len(self.wall.memory.episodic),
            "semantic": len(self.wall.memory.semantic),

            "working": len(self.wall.memory.working_memory),
            "tokens": self.wall.memory.get_token_estimate()
        })

    def get_psyche(self, npc_id: str) -> str:
        p = self.wall.psyche_mgr.get_psyche(npc_id)

            return json.dumps(p.to_dict())
        return json.dumps(None)

    def save_game(self, slot: str) -> str:
        self.wall.state.save_game(slot)
        self.wall.psyche_mgr.save_all()
        self.wall.memory.save()
        return json.dumps({"status": "saved"})

    def load_game(self, slot: str) -> str:
        self.wall.state.load_save(slot)
        return json.dumps({"status": "loaded"})

            "mode": self.wall.modes.current_mode,
            "hud": {
                "hp": 1.0, "stamina": 1.0, "mold": 0.0,
                "location": "Village Outskirts",
                "time": "Late Morning", "days": 18,
                "weather": "Heavy Snow"
            }
        })

        width=1100,
        height=750,
        min_size=(800, 500),
        resizable=True,

    )
    webview.start(debug=False)
```

### The Complexity Problem

We're at the inflection point where the engine is powerful and the UI is starting to buckle under the weight of features. The terminal aesthetic works BECAUSE it's simple. The moment you need a tabbed settings panel with dropdowns and sliders to configure your preset, you've built SillyTavern with a monospace font and worse documentation.

### The Answer: Two Layers

```
┌───────────────────────────────────────────────┐
│                                               │
│   THE SURFACE: the terminal                   │
│   Clean. Text. Commands. Portraits. HUD.      │
│   A player who never types a slash command     │
│   can play the entire game here. This layer    │
│   NEVER gets more complex.                    │
│                                               │
├───────────────────────────────────────────────┤
│                                               │
│   THE BASEMENT: config files                  │
│   YAML and JSON. Edited in any text editor.   │
│   Lorebooks, preset tuning, character         │
│   templates — all live here. Power users       │
│   open the files. Casual users never know     │
│   they exist.                                 │
│                                               │
└───────────────────────────────────────────────┘
```

The terminal doesn't grow more buttons. The data folder grows more files. That's the rule. Every new feature asks ONE question: **does this need a UI element, or does it need a config file?** Almost everything is a config file.

Each lorebook entry is one YAML file:

```yaml
# data/lorebook/characters/alcina.yaml

entry:
  name: "Alcina Dimitrescu"

  # trigger keywords — ANY match loads this entry
  keys:
    - "Alcina"
    - "Lady Dimitrescu"
    - "Mistress"
    - "Countess"

  # secondary keys — requires BOTH a primary AND secondary
  # match to trigger. Prevents "castle" loading Alcina
  # when you're just walking through.
  secondary_keys: []

  # when to inject into context
  position: "after_character"   # before_character | after_character | at_depth_N
  depth: null                   # only used if position is at_depth_N

  # priority (higher = loaded first when budget is tight)
  priority: 90

  # which modes this entry is active in
  modes: ["game", "story"]      # not freeform

  # scan depth — how many messages back to check for keywords
  scan_depth: 3

  # token budget for this entry
  max_tokens: 800

  # the actual content — can reference file or inline
  content_source: "characters/alcina/public.json"

  # OR inline content for simple lore entries:
  # content: |
  #   The Megamycete is a vast fungal superorganism...

  # conditional — only load if this state condition is true
  condition: null
  # example condition:
  # condition: "world.discovered_secrets contains 'miranda_is_hag'"

  # is this always loaded regardless of keywords?
  always_on: false

  # is this entry enabled?
  enabled: true
```

```python
# engine/lorebook.py — Lorebook manager

import yaml
import json
import re
from pathlib import Path
from typing import List, Optional


class LorebookEntry:
    def __init__(self, data, source_path=None):
        entry = data.get("entry", data)
        self.name = entry.get("name", "unnamed")
        self.keys = [k.lower() for k in entry.get("keys", [])]
        self.secondary_keys = [
            k.lower() for k in entry.get("secondary_keys", [])
        ]
        self.position = entry.get("position", "after_character")
        self.depth = entry.get("depth")
        self.priority = entry.get("priority", 50)
        self.modes = entry.get("modes", ["game", "story"])
        self.scan_depth = entry.get("scan_depth", 3)
        self.max_tokens = entry.get("max_tokens", 500)
        self.condition = entry.get("condition")
        self.always_on = entry.get("always_on", False)
        self.enabled = entry.get("enabled", True)
        self.source_path = source_path

        # load content
        content_source = entry.get("content_source")
        if content_source:
            full_path = Path("data") / content_source
            if full_path.exists():
                raw = full_path.read_text()
                # try JSON first, fall back to plain text
                try:
                    self.content = json.dumps(
                        json.loads(raw), indent=2
                    )
                except json.JSONDecodeError:
                    self.content = raw
            else:
                self.content = f"[missing: {content_source}]"
        else:
            self.content = entry.get("content", "")

    def matches(self, text_lower: str,
                require_secondary: bool = True) -> bool:
        """Check if this entry's keywords match the text."""
        if not self.enabled:
            return False
        if self.always_on:
            return True

        primary_match = any(k in text_lower for k in self.keys)
        if not primary_match:
            return False

        if self.secondary_keys and require_secondary:
            secondary_match = any(
                k in text_lower for k in self.secondary_keys
            )
            return secondary_match

        return True

    def check_condition(self, world_state: dict) -> bool:
        """Evaluate conditional loading."""
        if not self.condition:
            return True
        # simple condition parser
        # "world.discovered_secrets contains 'miranda_is_hag'"
        try:
            parts = self.condition.split(" contains ")
            if len(parts) == 2:
                path = parts[0].strip().split(".")
                value = parts[1].strip().strip("'\"")
                obj = world_state
                for key in path:
                    obj = obj.get(key, {})
                return value in obj if isinstance(obj, list) else False
        except Exception:
            return True  # fail open
        return True

    @property
    def token_estimate(self):
        return len(self.content) // 4


class Lorebook:
    """
    Manages all lorebook entries. Scans context for
    keyword matches and assembles relevant entries
    within token budget.
    """

    def __init__(self):
        self.entries: List[LorebookEntry] = []
        self.settings = self._load_settings()
        self._load_all_entries()

    def _load_settings(self):
        path = Path("data/lorebook/_settings.yaml")
        if path.exists():
            return yaml.safe_load(path.read_text())
        return {
            "default_scan_depth": 3,
            "max_total_tokens": 4000,
            "deduplication": True
        }

    def _load_all_entries(self):
        lorebook_dir = Path("data/lorebook")
        if not lorebook_dir.exists():
            return

        for yaml_path in lorebook_dir.rglob("*.yaml"):
            if yaml_path.name.startswith("_"):
                continue  # skip settings files
            try:
                data = yaml.safe_load(yaml_path.read_text())
                if data:
                    self.entries.append(
                        LorebookEntry(data, source_path=yaml_path)
                    )
            except Exception as e:
                print(f"Lorebook load error {yaml_path}: {e}")

    def scan_and_collect(self, messages: list,
                          world_state: dict,
                          current_mode: str,
                          token_budget: Optional[int] = None
                          ) -> dict:
        """
        Scan recent messages for keyword matches.
        Returns entries organized by injection position,
        within token budget, sorted by priority.

        Returns:
          {
            "before_character": [entries...],
            "after_character": [entries...],
            "at_depth": {2: [entries...], 4: [entries...]}
          }
        """
        budget = token_budget or self.settings.get(
            "max_total_tokens", 4000
        )

        # build scan text from recent messages
        scan_depth = self.settings.get("default_scan_depth", 3)
        recent = messages[-scan_depth:] if messages else []
        scan_text = " ".join(
            m.get("content", "") for m in recent
        ).lower()

        # find matching entries
        matched = []
        for entry in self.entries:
            if current_mode not in entry.modes:
                continue
            if not entry.check_condition(world_state):
                continue
            if entry.always_on or entry.matches(scan_text):
                matched.append(entry)

        # sort by priority (highest first)
        matched.sort(key=lambda e: e.priority, reverse=True)

        # fit within budget
        result = {
            "before_character": [],
            "after_character": [],
            "at_depth": {}
        }
        tokens_used = 0

        for entry in matched:
            if tokens_used + entry.token_estimate > budget:
                continue  # skip, over budget

            tokens_used += entry.token_estimate

            if entry.position == "before_character":
                result["before_character"].append(entry)
            elif entry.position == "after_character":
                result["after_character"].append(entry)
            elif entry.position.startswith("at_depth"):
                d = entry.depth or 2
                if d not in result["at_depth"]:
                    result["at_depth"][d] = []
                result["at_depth"][d].append(entry)

        return result

    def add_entry(self, entry_data: dict,
                   category: str = "custom"):
        """Add a new lorebook entry at runtime."""
        entry = LorebookEntry(entry_data)
        self.entries.append(entry)

        # save to disk
        save_dir = Path("data/lorebook") / category
        save_dir.mkdir(parents=True, exist_ok=True)
        safe_name = re.sub(r'[^\w]', '_', entry.name.lower())
        save_path = save_dir / f"{safe_name}.yaml"
        yaml.dump(
            {"entry": entry_data},
            save_path.open('w'),
            default_flow_style=False
        )

    def list_entries(self):
        """For /lorebook list command."""
        return [
            {
                "name": e.name,
                "keys": e.keys,
                "priority": e.priority,
                "enabled": e.enabled,
                "always_on": e.always_on,
                "tokens": e.token_estimate,
                "source": str(e.source_path) if e.source_path else "inline"
            }
            for e in sorted(self.entries,
                           key=lambda e: e.priority,
                           reverse=True)
        ]
```

```python
# additions to engine/commands.py

    # in _register_commands:
    "/lorebook": self.cmd_lorebook,
    "/lore": self.cmd_lorebook,  # alias

    async def cmd_lorebook(self, args):
        """
        /lorebook list              — list all entries
        /lorebook search [keyword]  — find entries by keyword
        /lorebook toggle [name]     — enable/disable entry
        /lorebook add "name" "keys" "content"  — quick add
        /lorebook reload            — reload from disk
        """
        if not args:
            args = ["list"]

        sub = args[0]

        if sub == "list":
            entries = self.wall.lorebook.list_entries()
            lines = ["═══ LOREBOOK ═══"]
            for e in entries:
                status = "✓" if e["enabled"] else "✗"
                star = "★" if e["always_on"] else " "
                lines.append(
                    f"  {status}{star} [{e['priority']:3d}] "
                    f"{e['name']} ({e['tokens']}t) "
                    f"keys: {', '.join(e['keys'][:3])}"
                )
            return CommandResult(
                success=True,
                message="\n".join(lines),
                suppress_turn=True
            )

        elif sub == "search":
            keyword = " ".join(args[1:]).lower()
            entries = [
                e for e in self.wall.lorebook.list_entries()
                if keyword in e["name"].lower()
                or keyword in " ".join(e["keys"])
            ]
            lines = [f"Search: '{keyword}'"]
            for e in entries:
                lines.append(f"  • {e['name']} (keys: {', '.join(e['keys'][:3])})")
            if not entries:
                lines.append("  (no matches)")
            return CommandResult(
                success=True,
                message="\n".join(lines),
                suppress_turn=True
            )

        elif sub == "toggle":
            name = " ".join(args[1:]).lower()
            for entry in self.wall.lorebook.entries:
                if entry.name.lower() == name:
                    entry.enabled = not entry.enabled
                    status = "enabled" if entry.enabled else "disabled"
                    return CommandResult(
                        success=True,
                        message=f"✓ {entry.name}: {status}",
                        suppress_turn=True
                    )
            return CommandResult(
                success=False,
                message=f"Entry not found: {name}"
            )

        elif sub == "reload":
            self.wall.lorebook = Lorebook()
            count = len(self.wall.lorebook.entries)
            return CommandResult(
                success=True,
                message=f"✓ Reloaded {count} entries from disk",
                suppress_turn=True
            )

        return CommandResult(
            success=False,
            message="Usage: /lorebook [list|search|toggle|add|reload]"
        )
```

The preset manager now reads all of this:

```python
# engine/presets.py — Updated for full depth

class PresetManager:
    def __init__(self, active_model=None):
        self.presets_dir = Path("data/presets")
        self.presets_dir.mkdir(parents=True, exist_ok=True)
        self.active_preset = "balanced"
        self.active_model = active_model
        self.presets = {}
        self._init_defaults()
        self._load_all()

    def _load_all(self):
        for path in self.presets_dir.glob("*.yaml"):
            try:
                data = yaml.safe_load(path.read_text())
                self.presets[path.stem] = data
            except Exception as e:
                print(f"Preset load error {path}: {e}")

    def get_sampling_params(self):
        """
        Returns API-ready sampling params, with
        model-specific overrides applied.
        """
        preset = self.presets.get(
            self.active_preset,
            self.presets.get("balanced", {})
        )

        # base params
        params = {
            "temperature": preset.get("temperature", 0.8),
            "top_p": preset.get("top_p", 0.95),
            "top_k": preset.get("top_k", 40),
            "max_tokens": preset.get("max_tokens", 1500),
        }

        # optional params (only include if set)
        optional = [
            "min_p", "typical_p", "repetition_penalty",
            "repetition_penalty_range", "frequency_penalty",
            "presence_penalty", "stop_sequences"
        ]
        for key in optional:
            if key in preset:
                params[key] = preset[key]

        # model-specific overrides
        if self.active_model:
            overrides = preset.get("model_overrides", {})
            # match partial model name
            for model_pattern, model_params in overrides.items():
                if model_pattern in self.active_model:
                    params.update(model_params)
                    break

        return params

    def get_banned_strings(self):
        preset = self.presets.get(self.active_preset, {})
        return preset.get("banned_strings", [])

    def get_prompt_format(self):
        preset = self.presets.get(self.active_preset, {})
        return preset.get("prompt_format", "anthropic")
```

### Wiring the Lorebook Into the Wall

The lorebook needs to plug into three places: the Wall's context builder, the narrator's prompt assembly, and the mode-aware pipeline. Here's the full integration:

```python
# engine/wall.py — Lorebook integration

from engine.lorebook import Lorebook

class Wall:

    def __init__(self, config):
        self.gm = GameMaster(config)
        self.narrator = Narrator(config)
        self.state = StateManager()
        self.psyche_mgr = PsycheManager()
        self.memory = MemoryBank()
        self.presets = PresetManager(
            active_model=config.get("narrator_model")
        )
        self.modes = ModeManager()
        self.lorebook = Lorebook()           # ★ NEW
        self.commands = CommandRouter(
            wall=self,
            psyche_mgr=self.psyche_mgr,
            memory=self.memory,
            presets=self.presets,
            mode_mgr=self.modes
        )
        self.revelation_log = []
        self._feedback_queue = []
        self.turn_count = 0

    def build_narrator_context(self, briefing, npcs_present,
                                working_memory="",
                                feedback=None):
        """
        THE WALL — game mode context assembly.
        Now with lorebook injection at correct positions.
        """

        # ── STEP 1: Scan lorebook ──
        lorebook_entries = self.lorebook.scan_and_collect(
            messages=self.state.chat_history,
            world_state=self.state.world,
            current_mode=self.modes.current_mode,
            token_budget=self.lorebook.settings.get(
                "max_total_tokens", 4000
            )
        )

        # ── STEP 2: Build the context layers ──
        # The narrator receives a structured context dict.
        # The narrator.generate() method assembles this into
        # the actual API message array, injecting lorebook
        # entries at their specified positions.

        context = {
            "system": self.modes.get_narrator_prompt(),

            # lorebook entries that go BEFORE the world card
            "pre_world": self._entries_to_text(
                lorebook_entries["before_character"]
            ),

            # the world card itself
            "world": self.state.world_public,

            # lorebook entries that go AFTER the world card
            "post_world": self._entries_to_text(
                lorebook_entries["after_character"]
            ),

            # gated character cards for present NPCs
            "characters": {},

            # the briefing from the GM
            "briefing": {
                "scene_context": briefing["scene_context"],
                "action_resolution": briefing[
                    "action_resolution"
                ],
                "npc_direction": briefing["npc_direction"],
                "revealed_info": self.revelation_log,
            },

            # psyche summaries (narrator-safe surface)
            "npc_psychology": {},

            # working memory
            "working_memory": working_memory,

            # feedback anchors
            "feedback": feedback or [],

            # chat history
            "chat_history": self.state.chat_history[-20:],

            # lorebook entries injected at specific depths
            # in the chat history
            "depth_injections": {
                depth: self._entries_to_text(entries)
                for depth, entries
                in lorebook_entries["at_depth"].items()
            },

            # author's note
            "authors_note": self.state.authors_note
        }

        # load gated character cards
        for npc in npcs_present:
            context["characters"][npc] = (
                self.state.get_narrator_card(
                    npc, self.revelation_log
                )
            )

        # psyche surface for narrator
        for npc in npcs_present:
            p = self.psyche_mgr.get_psyche(npc)
            if p and p.appraisal:
                context["npc_psychology"][npc] = {
                    "current_appraisal": p.appraisal,
                    "emotional_state": {
                        name: round(e.current, 2)
                        for name, e in p.emotions.items()
                    }
                }

        return context

    def build_story_context(self, npcs_present,
                             working_memory="",
                             feedback=None):
        """
        Story mode context — no Wall, full cards,
        but lorebook still fires for lore/location entries.
        """
        lorebook_entries = self.lorebook.scan_and_collect(
            messages=self.state.chat_history,
            world_state=self.state.world,
            current_mode="story",
            token_budget=self.lorebook.settings.get(
                "max_total_tokens", 4000
            )
        )

        context = {
            "system": self.modes.get_narrator_prompt(),
            "pre_world": self._entries_to_text(
                lorebook_entries["before_character"]
            ),
            "world": self.state.world_public,
            "post_world": self._entries_to_text(
                lorebook_entries["after_character"]
            ),
            "characters": {},
            "npc_psychology": {},
            "working_memory": working_memory,
            "feedback": feedback or [],
            "chat_history": self.state.chat_history[-30:],
            "depth_injections": {
                depth: self._entries_to_text(entries)
                for depth, entries
                in lorebook_entries["at_depth"].items()
            },
            "authors_note": self.state.authors_note
        }

        # FULL cards in story mode (no split)
        for npc_id in npcs_present:
            char_dir = Path("data/characters") / npc_id
            public_path = char_dir / "public.json"
            private_path = char_dir / "private.json"
            card = {}
            if public_path.exists():
                card = json.loads(public_path.read_text())
            if private_path.exists():
                card.update(
                    json.loads(private_path.read_text())
                )
            context["characters"][npc_id] = card

        # psyche surfaces
        if self.modes.psyche_active:
            for npc in npcs_present:
                p = self.psyche_mgr.get_psyche(npc)
                if p:
                    context["npc_psychology"][npc] = p.to_dict()

        return context

    @staticmethod
    def _entries_to_text(entries):
        """Convert lorebook entries to injectable text."""
        if not entries:
            return ""
        blocks = []
        for entry in entries:
            blocks.append(
                f"[LOREBOOK: {entry.name}]\n{entry.content}"
            )
        return "\n\n".join(blocks)
```

### The Narrator — Prompt Assembly With Injection Points

This is where the lorebook entries actually land in the API call. The narrator takes the structured context and builds the message array with entries at the correct positions:

```python
# engine/narrator.py — Full prompt assembly

import json
import httpx

class Narrator:
    def __init__(self, config):
        self.api_key = config.get("narrator_api_key",
                                   config.get("haiku_api_key"))
        self.model = config.get("narrator_model",
                                 "claude-sonnet-4-20250514")
        self.endpoint = config.get("api_endpoint",
            "https://api.anthropic.com/v1/messages")
        self.context_window = config.get(
            "narrator_context_window", 32000
        )

    async def generate(self, context: dict,
                        player_input: str,
                        sampling_params: dict = None
                        ) -> str:
        """
        Assemble the full prompt and generate a response.

        PROMPT STRUCTURE (top to bottom = how model reads):

        ┌─ SYSTEM MESSAGE ─────────────────────────┐
        │  1. Narrator system prompt                │
        │  2. Pre-world lorebook entries             │
        │  3. World card                            │
        │  4. Post-world lorebook entries            │
        │  5. Character cards (present NPCs)        │
        │  6. NPC psychology (if available)          │
        │  7. Working memory                        │
        │  8. Feedback anchors                      │
        │  9. Briefing packet (game mode only)      │
        └───────────────────────────────────────────┘
        ┌─ CHAT HISTORY ───────────────────────────┐
        │  Messages, with depth-injected lorebook   │
        │  entries inserted at specified positions   │
        └───────────────────────────────────────────┘
        ┌─ AUTHOR'S NOTE (near bottom) ────────────┐
        └───────────────────────────────────────────┘
        ┌─ PLAYER MESSAGE (last, highest weight) ──┐
        └───────────────────────────────────────────┘
        """

        # ── BUILD SYSTEM PROMPT ──
        system_parts = [context.get("system", "")]

        # pre-world lorebook
        pre_world = context.get("pre_world", "")
        if pre_world:
            system_parts.append(pre_world)

        # world card
        world = context.get("world", {})
        if world:
            if isinstance(world, dict):
                system_parts.append(
                    f"[WORLD STATE]\n{json.dumps(world, indent=2)}"
                )
            else:
                system_parts.append(f"[WORLD STATE]\n{world}")

        # post-world lorebook
        post_world = context.get("post_world", "")
        if post_world:
            system_parts.append(post_world)

        # character cards
        characters = context.get("characters", {})
        if characters:
            char_block = ["[CHARACTERS PRESENT]"]
            for npc_id, card in characters.items():
                if isinstance(card, dict):
                    char_block.append(
                        f"\n── {npc_id.upper()} ──\n"
                        f"{json.dumps(card, indent=2)}"
                    )
                else:
                    char_block.append(
                        f"\n── {npc_id.upper()} ──\n{card}"
                    )
            system_parts.append("\n".join(char_block))

        # npc psychology
        psych = context.get("npc_psychology", {})
        if psych:
            psych_block = ["[NPC PSYCHOLOGICAL STATE]"]
            for npc_id, state in psych.items():
                psych_block.append(
                    f"  {npc_id}: {json.dumps(state)}"
                )
            system_parts.append("\n".join(psych_block))

        # working memory
        working_mem = context.get("working_memory", "")
        if working_mem:
            system_parts.append(working_mem)

        # feedback anchors
        feedback = context.get("feedback", [])
        if feedback:
            system_parts.append(
                "[ACTIVE BEHAVIORAL ANCHORS]\n" +
                "\n".join(feedback)
            )

        # briefing (game mode only)
        briefing = context.get("briefing")
        if briefing:
            system_parts.append(
                f"[GM BRIEFING]\n"
                f"{json.dumps(briefing, indent=2)}"
            )

        system_message = "\n\n".join(
            part for part in system_parts if part
        )

        # ── BUILD MESSAGE ARRAY ──
        messages = []

        # chat history with depth injections
        history = context.get("chat_history", [])
        depth_injections = context.get("depth_injections", {})
        authors_note = context.get("authors_note", "")

        # depth is measured from the BOTTOM
        # depth 0 = last message, depth 2 = 2 from bottom, etc
        # we need to calculate injection points

        # first, build the history array
        history_with_injections = list(history)

        # inject author's note at depth 2 (2 from bottom)
        an_depth = 2
        an_position = max(0, len(history_with_injections) - an_depth)
        if authors_note:
            history_with_injections.insert(
                an_position,
                {
                    "role": "system_injection",
                    "content": f"[AUTHOR'S NOTE]\n{authors_note}"
                }
            )

        # inject depth lorebook entries
        for depth, text in sorted(
            depth_injections.items(),
            key=lambda x: x[0],
            reverse=True  # inject deepest first to preserve positions
        ):
            position = max(
                0,
                len(history_with_injections) - int(depth)
            )
            if text:
                history_with_injections.insert(
                    position,
                    {
                        "role": "system_injection",
                        "content": text
                    }
                )

        # now convert to API message format
        # system_injection messages get folded into adjacent
        # assistant messages or become standalone user messages
        # depending on API format

        for msg in history_with_injections:
            role = msg.get("role", "user")
            content = msg.get("content", "")

            if role == "system_injection":
                # Anthropic API doesn't have a "system" role
                # in messages — inject as user message with
                # clear framing
                messages.append({
                    "role": "user",
                    "content": f"[SYSTEM]\n{content}"
                })
                messages.append({
                    "role": "assistant",
                    "content": "[Understood, integrating.]"
                })
            else:
                messages.append({
                    "role": role,
                    "content": content
                })

        # add current player input
        messages.append({
            "role": "user",
            "content": player_input
        })

        # ── TOKEN BUDGET CHECK ──
        estimated_tokens = self._estimate_tokens(
            system_message, messages
        )
        if estimated_tokens > self.context_window * 0.85:
            messages = self._trim_history(
                messages, system_message
            )

        # ── API CALL ──
        params = sampling_params or {}
        api_body = {
            "model": self.model,
            "max_tokens": params.pop("max_tokens", 1500),
            "system": system_message,
            "messages": messages,
        }

        # add sampling params (only supported ones per API)
        supported_params = [
            "temperature", "top_p", "top_k",
            "stop_sequences"
        ]
        for key in supported_params:
            if key in params:
                api_body[key] = params[key]

        async with httpx.AsyncClient() as client:
            response = await client.post(
                self.endpoint,
                headers={
                    "x-api-key": self.api_key,
                    "content-type": "application/json",
                    "anthropic-version": "2023-06-01"
                },
                json=api_body,
                timeout=60.0
            )

        result = response.json()

        if "content" in result and result["content"]:
            return result["content"][0]["text"]
        elif "error" in result:
            return f"[NARRATOR ERROR: {result['error'].get('message', 'unknown')}]"
        return "[NARRATOR ERROR: empty response]"

    async def quick_task(self, task_json: str) -> dict:
        """
        For non-narrative tasks (memory summarization, etc).
        Uses lower max_tokens and precise preset.
        """
        async with httpx.AsyncClient() as client:
            response = await client.post(
                self.endpoint,
                headers={
                    "x-api-key": self.api_key,
                    "content-type": "application/json",
                    "anthropic-version": "2023-06-01"
                },
                json={
                    "model": self.model,
                    "max_tokens": 500,
                    "temperature": 0.3,
                    "system": (
                        "You are a data extraction assistant. "
                        "Output ONLY valid JSON. No commentary."
                    ),
                    "messages": [{
                        "role": "user",
                        "content": task_json
                    }]
                },
                timeout=30.0
            )

        try:
            result = response.json()
            text = result["content"][0]["text"]
            return json.loads(text)
        except (KeyError, json.JSONDecodeError):
            return None

    def _estimate_tokens(self, system: str,
                          messages: list) -> int:
        """Rough token estimation."""
        total_chars = len(system)
        for msg in messages:
            total_chars += len(msg.get("content", ""))
        return total_chars // 4

    def _trim_history(self, messages: list,
                       system: str) -> list:
        """
        Trim oldest non-injection messages to fit
        context window. Preserves:
        - system injections (lorebook, author's note)
        - the last 6 messages minimum
        - the current player input (always last)
        """
        target = int(self.context_window * 0.7)
        system_tokens = len(system) // 4

        # separate protected and trimmable
        current_input = messages[-1]  # always keep
        remaining = messages[:-1]

        protected = []
        trimmable = []

        for msg in remaining:
            if msg.get("content", "").startswith("[SYSTEM]"):
                protected.append(msg)
            elif msg.get("content") == "[Understood, integrating.]":
                protected.append(msg)
            else:
                trimmable.append(msg)

        # keep last 6 trimmable messages minimum
        keep_minimum = 6
        if len(trimmable) > keep_minimum:
            must_keep = trimmable[-keep_minimum:]
            can_trim = trimmable[:-keep_minimum]
        else:
            must_keep = trimmable
            can_trim = []

        # estimate current size
        current_tokens = system_tokens + sum(
            len(m.get("content", "")) // 4
            for m in protected + must_keep + [current_input]
        )

        # add back from can_trim (newest first) until budget
        restored = []
        for msg in reversed(can_trim):
            msg_tokens = len(msg.get("content", "")) // 4
            if current_tokens + msg_tokens < target:
                restored.insert(0, msg)
                current_tokens += msg_tokens
            else:
                break

        # reassemble in order
        # protected injections go back to their approximate
        # positions relative to the kept messages
        final = restored + must_keep

        # reinsert protected at their relative positions
        # (simplified: just put them where they were)
        result = []
        prot_idx = 0
        trim_idx = 0

        for orig_msg in remaining:
            if (prot_idx < len(protected) and
                    orig_msg is protected[prot_idx]):
                result.append(protected[prot_idx])
                prot_idx += 1
            elif trim_idx < len(final) and orig_msg in final:
                result.append(orig_msg)
                trim_idx += 1
            # else: trimmed, skip

        # catch any remaining
        while prot_idx < len(protected):
            result.append(protected[prot_idx])
            prot_idx += 1

        result.append(current_input)
        return result
```

```python
    async def _game_turn(self, player_input):

        # 1. Scene NPCs and psyche

            feedback=feedback
        )

        # 5. State updates

        # 6. Psyche updates from GM

                if psyche:

                        if drive in psyche.drives:

                    ):
                        if emotion in psyche.emotions:
                            psyche.emotions[emotion].spike(delta)
                    if "appraisal" in updates:
                        psyche.appraisal = updates["appraisal"]

        # 7. Tick psyches
        self.psyche_mgr.tick_all()

        # 8. Track revelations
        newly_revealed = briefing["information_release"].get(
            "reveal_this_turn", []
        )
        self.revelation_log.extend(newly_revealed)

        # ★ 9. Build narrator context WITH lorebook
        narrator_context = self.build_narrator_context(
            briefing=briefing,

                "scene_context"

            working_memory=working_mem,
            feedback=feedback
        )
        # lorebook scanning happens INSIDE build_narrator_context
        # entries are injected at their specified positions

        # 10. Sampling params
        sampling = self.presets.get_sampling_params()

        # 11. Narrator generates
        prose = await self.narrator.generate(
            context=narrator_context,
            player_input=player_input,
            sampling_params=sampling
        )

        # 12. Post-generation: banned string filter
        banned = self.presets.get_banned_strings()
        for string in banned:
            if string.lower() in prose.lower():
                prose = prose.replace(string, "")

        # 13. Memory summarization
        if self.modes.memory_active:
            scene_text = (
                f"Player: {player_input}\n\n"
                f"Narrator: {prose}"
            )
            summary_prompt = self.memory.summarize_scene(
                scene_text=scene_text,
                gm_client=self.gm,
                turn_number=self.turn_count
            )
            summary_data = await self.gm.quick_summarize(
                summary_prompt
            )
            if summary_data:
                self.memory.ingest_summary(
                    summary_data, self.turn_count
                )

        # 14. Save psyches
        self.psyche_mgr.save_all()

        # 15. Update scene NPC tracking for next turn
        self.state.world["_current_scene_npcs"] = (
            briefing["scene_context"]["npcs_present"]
        )

        return {
            "prose": prose,
            "hud": briefing["hud_data"]
                if self.modes.hud_active else None,
            "portraits": self.get_portraits(
                npcs=briefing[
                    "scene_context"
                ]["npcs_present"],
                states=briefing.get("npc_states", {})
            ),
            "fragments": briefing[
                "information_release"
            ].get("fragment_trigger", None),
            "command_result": False
        }

    async def _story_turn(self, player_input):

        if self.modes.psyche_active:

            feedback=feedback
        )

        sampling = self.presets.get_sampling_params()
        prose = await self.narrator.generate(
            context=context,
            player_input=player_input,
            sampling_params=sampling
        )

        # banned strings
        for string in self.presets.get_banned_strings():

        # memory
        if self.modes.memory_active:
            scene_text = (

            "hud": None,

            ),
            "fragments": None,
            "command_result": False
```

### Quick Verification — The Full Injection Flow

Here's exactly what happens to a lorebook entry from disk to the API call, so we can confirm nothing's broken:

```
1. DISK
   data/lorebook/characters/alcina.yaml
   keys: ["alcina", "lady dimitrescu"]
   position: "after_character"
   priority: 90
   content_source: "characters/alcina/public.json"

2. LOAD (app start)
   Lorebook.__init__() → _load_all_entries()
   → LorebookEntry created, content loaded from
     data/characters/alcina/public.json

3. SCAN (every turn)
   Wall.build_narrator_context()
   → lorebook.scan_and_collect()
   → scans last 3 messages for "alcina" or
     "lady dimitrescu"
   → MATCH: player said "I approach Lady Dimitrescu"
   → entry added to results["after_character"] list

4. INJECT
   Wall.build_narrator_context()
   → _entries_to_text(lorebook_entries["after_character"])
   → "[LOREBOOK: Alcina Dimitrescu]\n{card content}"
   → placed in context["post_world"]

5. ASSEMBLE
   Narrator.generate()
   → system_parts builds in order:
     1. narrator prompt
     2. pre_world lorebook (game system rules, etc)
     3. world card
     4. post_world lorebook (Alcina's card lands HERE)
     5. character cards from briefing
     6. npc psychology
     7. working memory
     8. feedback
     9. briefing
```

### Wait — Potential Overlap Issue

There's a subtle thing to address. In game mode, the briefing packet ALSO contains character direction from the GM. And the lorebook might ALSO load a character card for the same NPC. That's redundant tokens.

Fix:

```python
# engine/wall.py — deduplication in build_narrator_context

    def build_narrator_context(self, briefing, npcs_present,
                                working_memory="",
                                feedback=None):
        # ── Scan lorebook ──
        lorebook_entries = self.lorebook.scan_and_collect(
            messages=self.state.chat_history,
            world_state=self.state.world,
            current_mode=self.modes.current_mode,
            token_budget=self.lorebook.settings.get(
                "max_total_tokens", 4000
            )
        )

        # ★ DEDUPLICATION: if a character card is already
        # loaded via the gated card system (npcs_present),
        # remove their lorebook entry to avoid double-loading.
        present_names = set()
        for npc_id in npcs_present:
            # map npc_id to possible lorebook entry names
            present_names.add(npc_id)
            # also add common name variants
            char_dir = Path("data/characters") / npc_id
            public_path = char_dir / "public.json"
            if public_path.exists():
                card = json.loads(public_path.read_text())
                identity = card.get("identity", "")
                # extract first name as a key
                if identity:
                    first_word = identity.split("|")[0].strip().split()[0]
                    present_names.add(first_word.lower())

        # filter lorebook entries — remove character entries
        # for NPCs already in npcs_present
        for position in ["before_character", "after_character"]:
            lorebook_entries[position] = [
                entry for entry in lorebook_entries[position]
                if not any(
                    name in entry.name.lower()
                    for name in present_names
                )
            ]
        for depth in list(lorebook_entries["at_depth"].keys()):
            lorebook_entries["at_depth"][depth] = [
                entry for entry
                in lorebook_entries["at_depth"][depth]
                if not any(
                    name in entry.name.lower()
                    for name in present_names
                )
            ]

        # ... rest of context building as before ...
```

This way: if Alcina is in the scene, her card loads via the gated card system (Wall-controlled, possibly private sections released). The lorebook version does NOT also load. No double-spending tokens. But if someone MENTIONS Alcina while she's not in the scene ("I need to ask the Duke about Lady Dimitrescu"), the lorebook CAN fire and load her public card as reference context.

```python
    def _build_tree(self, path, lines, prefix,
                     max_depth, current_depth):
        if current_depth >= max_depth:
            return
        try:
            entries = sorted(path.iterdir())
        except PermissionError:
            return
        for i, entry in enumerate(entries):
            is_last = (i == len(entries) - 1)
            connector = "└── " if is_last else "├── "
            if entry.is_dir():
                lines.append(f"{prefix}{connector}📁 {entry.name}/")
                extension = "    " if is_last else "│   "
                self._build_tree(
                    entry, lines, prefix + extension,
                    max_depth, current_depth + 1
                )
            else:
                lines.append(f"{prefix}{connector}{entry.name}")

            "pc": self.wall.state.pc,
            "world": self.wall.state.world,
            "vault": self.wall.state.vault,
        }

        if root_key not in targets:
            return self._error(
                f"Unknown root: {root_key}. "
                f"Use: pc, world, vault"
            )

        obj = targets[root_key]
        for key in path[1:-1]:
            if key not in obj:
                obj[key] = {}
            obj = obj[key]

        old_value = obj.get(path[-1], "(not set)")
        obj[path[-1]] = value

        return self._success(
            f"✓ {path_str}\n"
            f"  was: {old_value}\n"
            f"  now: {value}"
        )

    async def cmd_inject(self, args):
        """
        /dev inject [target] [content]
        Inject content directly into a system.

        /dev inject memory_episodic "The soldier found a hidden passage"
        /dev inject memory_semantic "Alcina fears cold"
        /dev inject revelation "alcina_hates_miranda"
        /dev inject psyche alcina anger 0.3
        /dev inject commitment alcina "Test the stranger's resolve"
        """
        if not self.dev.is_enabled():
            return self._disabled()
        if len(args) < 2:
            return self._usage("inject [target] [content]")

        target = args[0]

        if target.startswith("memory_"):
            mem_type = target.replace("memory_", "")
            content = " ".join(args[1:])
            self.wall.memory.add(
                content=content,
                memory_type=mem_type,
                importance=0.8,
                turn=self.wall.turn_count
            )
            return self._success(
                f"✓ Injected {mem_type} memory: {content}"
            )

        elif target == "revelation":
            content = " ".join(args[1:])
            self.wall.revelation_log.append(content)
            return self._success(
                f"✓ Added revelation: {content}"
            )

        elif target == "psyche":
            if len(args) < 4:
                return self._usage(
                    "inject psyche [npc] [emotion] [delta]"
                )
            npc_id = args[1]
            emotion = args[2]
            delta = float(args[3])
            p = self.wall.psyche_mgr.get_psyche(npc_id)
            if p and emotion in p.emotions:
                old = p.emotions[emotion].current
                p.emotions[emotion].spike(delta)
                return self._success(
                    f"✓ {npc_id}.{emotion}: "
                    f"{old:.3f} → {p.emotions[emotion].current:.3f}"
                )
            return self._error(f"Psyche or emotion not found")

        elif target == "commitment":
            npc_id = args[1]
            goal = " ".join(args[2:])
            p = self.wall.psyche_mgr.get_psyche(npc_id)
            if p:
                p.commitments.append(
                    Commitment(goal=goal, intensity=0.7)
                )
                return self._success(
                    f"✓ Added commitment to {npc_id}: {goal}"
                )
            return self._error(f"No psyche for {npc_id}")

        return self._error(f"Unknown inject target: {target}")

    # ════════════════════════════════════════════
    # EXECUTION
    # ════════════════════════════════════════════

    async def cmd_exec(self, args):
        """
        /dev exec [python_expression]
        Execute a Python expression and show result.
        DANGEROUS. Only in dev mode. Use carefully.

        /dev exec len(self.wall.state.chat_history)
        /dev exec self.wall.psyche_mgr.active.keys()
        /dev exec [e.name for e in self.wall.lorebook.entries]
        """
        if not self.dev.is_enabled():
            return self._disabled()
        if not args:
            return self._usage("exec [python_expression]")

        expression = " ".join(args)
        try:
            # limited scope for safety
            result = eval(
                expression,
                {"__builtins__": {}},
                {
                    "self": self,
                    "wall": self.wall,
                    "json": json,
                    "Path": Path,
                    "len": len,
                    "list": list,
                    "dict": dict,
                    "str": str,
                    "int": int,
                    "float": float,
                    "sorted": sorted,
                    "print": print,
                }
            )
            return self._success(f">>> {expression}\n{result}")
        except Exception as e:
            return self._error(
                f">>> {expression}\n"
                f"Error: {traceback.format_exc()}"
            )

    async def cmd_run(self, args):
        """
        /dev run [shell_command]
        Run a shell command. Output captured.
        VERY DANGEROUS. Dev mode only.

        /dev run python -m pytest tests/
        /dev run cat data/characters/alcina/public.json
        /dev run wc -l engine/*.py
        """
        if not self.dev.is_enabled():
            return self._disabled()
        if not args:
            return self._usage("run [shell_command]")

        command = " ".join(args)
        try:
            result = subprocess.run(
                command,
                shell=True,
                capture_output=True,
                text=True,
                timeout=30,
                cwd=str(self.dev.project_root)
            )
            output = result.stdout
            if result.stderr:
                output += f"\n[STDERR]\n{result.stderr}"
            output = output[:3000]
            return self._success(
                f"$ {command}\n"
                f"(exit {result.returncode})\n\n"
                f"{output}"
            )
        except subprocess.TimeoutExpired:
            return self._error(f"Timeout: {command}")
        except Exception as e:
            return self._error(f"Exec failed: {str(e)}")

    # ════════════════════════════════════════════
    # HELPERS
    # ════════════════════════════════════════════

    def _disabled(self):
        return CommandResult(
            success=False,
            message="Dev mode is not enabled. Set dev_mode: true in config.yaml",
            suppress_turn=True
        )

    def _usage(self, usage):
        return CommandResult(
            success=False,
            message=f"Usage: /dev {usage}",
            suppress_turn=True
        )

    def _error(self, msg):
        return CommandResult(
            success=False,
            message=f"✗ {msg}",
            suppress_turn=True
        )

    def _success(self, msg):
        return CommandResult(
            success=True,
            message=msg,
            suppress_turn=True
        )
```

Wire it into the command router:

```python
# additions to engine/commands.py

    # in __init__:
    self.devtools = DevTools(wall.config if hasattr(wall, 'config') else {})
    self.dev_commands = DevCommands(self.devtools, wall)

    # in _register_commands:

    async def cmd_dev(self, args):
        """
        /dev [subcommand] [args]
        Developer tools. Requires dev_mode: true in config.yaml.

        /dev read [file]         — read a file
        /dev write [file] [data] — write a file
        /dev ls [path]           — list directory
        /dev tree [path] [depth] — directory tree
        /dev inspect [target]    — inspect system state
        /dev test [target]       — run component tests
        /dev patch [path] [val]  — patch state values

        /dev exec [expression]   — evaluate Python expression
        /dev run [command]       — run shell command
        """
        if not args:
            return CommandResult(
                success=True,
                message=(
                    "═══ DEV TOOLS ═══\n"
                    f"  Status: {'ENABLED' if self.devtools.is_enabled() else 'DISABLED'}\n"
                    "  Subcommands:\n"
                    "    read, write, ls, tree\n"
                    "    inspect, test\n"
                    "    patch, inject\n"
                    "    exec, run\n"
                    "  Type /dev [subcommand] for usage"
                ),
                suppress_turn=True
            )

        sub = args[0]
        sub_args = args[1:]

        handler_map = {
            "read": self.dev_commands.cmd_read,
            "write": self.dev_commands.cmd_write,
            "ls": self.dev_commands.cmd_ls,
            "tree": self.dev_commands.cmd_tree,
            "inspect": self.dev_commands.cmd_inspect,
            "test": self.dev_commands.cmd_test,
            "patch": self.dev_commands.cmd_patch,
            "inject": self.dev_commands.cmd_inject,
            "exec": self.dev_commands.cmd_exec,
            "run": self.dev_commands.cmd_run,
        }

        handler = handler_map.get(sub)
        if handler:
            return await handler(sub_args)

        return CommandResult(
            success=False,
            message=f"Unknown dev subcommand: {sub}",
            suppress_turn=True
        )
```

### THE ACTUAL ANSWER TO YOUR QUESTION

Here's the honest picture:

**SillyTavern can't do this.** The SillyTavern extension system is a modular framework that allows third-party code to hook into the application lifecycle. Extensions are primarily client-side JavaScript modules loaded from the public/scripts/extensions/ directory. Extensions can access core APIs, inject prompts into generation requests, register slash commands, subscribe to application events, and maintain their own settings. That's prompt injection and UI hooks — not file system access, not code execution, not the kind of deep introspection you're asking about.

**Claude Code is the build tool.** Use it to actually construct The Valley app from our design docs. It reads your codebase, writes files, runs tests, debugs failures. A new generation of CLI tools lets you describe what you want in plain English and watch an agent edit files, run tests, commit code, and debug failures, all without leaving your terminal.

**The Valley's `/dev` mode is the runtime tool.** Once the app is built and running, `/dev` gives you Claude-Code-like introspection FROM INSIDE the game:

```
WHAT YOU CAN DO IN /DEV MODE:

/dev read engine/wall.py        ← read any file
/dev write data/test.json {...} ← write any file
/dev ls engine/                 ← browse the project
```
